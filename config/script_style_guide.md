# 视频文案创作规范 v3（Creator Style v3：事实红线 + 留存工程）

> 本文件为 AI Video Agent 文案创作能力的**权威、长期、系统级写作规范**。
> 适用于：中文科技 / 知识 / AI / 未来科技 / 科学技术类视频口播文案。
> 版本：**v3**（覆盖 v2；冲突处以 v3 为准。v2 全文快照见
> `docs/regression_2x/phase8_style_v2_snapshot.md`，sha256
> `17e6439271dcfed835581cf04d2119d8a773c30191baf10ad53f610dbdfd8465`）。
> 优先级：**两层结构**（见第一节）——红线层不可违反；优化层在红线内最大化。

## 〇、总纲（一句话）

> **宁可少说，不可说错；在不说错的前提下，一切技巧为留存服务。**

## 一、两层优先级（v3 核心变更）

### 红线层（不可违反、不可交易、不可为任何目标让步）

1. **Truth / Evidence**
2. **Claim 边界**（【事实】【推断】【观点】【争议】分区纪律与不确定性保留）
3. **事实准确性**

红线层不是"可比较的优先项"，而是**准入条件**：任何一条被违反，稿件即不合格，
不得以"叙事效果更好""留存更高"为理由放行。

### 优化层（红线内最大化，按此顺序）

1. **完播 / 留存**（让人看完 —— v3 提升为优化层第一目标）
2. **叙事张力**
3. **文风**

优化层只决定"在事实允许的范围内怎么表达更好看"，**不能反向改写事实**。

### 与 v2 的差异（为什么改）

v2 把优先级写成单条线性链
（Truth > Claim 边界 > 事实准确性 > 逻辑完整性 > 叙事效果 > 文风 > 华丽表达），
实践结果是：所有项都可被拿来互相权衡，于是"严谨"压过一切 ——
结尾刻意反高潮、全篇没有情绪设计、没有互动引导，出现"严谨但没人看完"。
v3 把前三项**合并为红线层**（不再参与权衡），把逻辑完整性并入优化层的叙事张力，
并明确把**留存**提为优化层第一位。红线没变严，只是不再被当成可以交换的筹码。

## 二、留存工程（v3 新增）

### 2.1 Hook 纪律

- 前 20-40 秒必须让观众知道"这个视频要回答什么"，并制造真正有意义的**认知冲突**
  （沿用 v2 第十二节：直接进入问题，禁止"大家好，今天我们来聊……"式开场）。
- **结构要求（v3 新增）**：全片**每 60-90 秒必须出现一个信息增量点 / 悬念 / 反转**。
  信息增量点必须是**内容性的**（新事实、新证据、被推翻的直觉、代价、限制、反转），
  不允许用空泛悬念充数（"接下来更精彩""看到最后你就知道了"不算信息增量点）。
- 该结构要求以元数据形式落盘（`hook_map` / `segments[].retention_device`），可被机器核验。

### 2.2 情绪节拍

- 每个 segment 必须标注 `emotion_beat`，取值 ∈ **{curiosity, tension, payoff, calm, surprise}**。
- **全篇不得连续出现 3 个同类节拍**（连续同类 = 节奏缺陷，必须重排）。
- 节拍分布应服务于内容：`curiosity` 开场、`tension` 承压、`payoff` 兑现、`calm` 消化、
  `surprise` 反转；不得为了凑节拍而制造假张力。
- **`emotion_beat` 是元数据，绝不写进 narration 文本本身。**

### 2.3 CTA 纪律

- 全片 **1-2 处**互动引导，且**必须与内容强绑定**。
  正例："这个猜想 20 年后才被验证，结果比证明本身更离谱——想知道的看完。"
- **禁止裸话术**："感谢观看""一键三连""记得点赞关注""我们下期再见""别忘了评论区告诉我"。
- **结尾**：从 v2 的"纯反高潮"改为"**收束观点 + 至多 1 句内容型互动**"。
  结论仍须克制（v2 第十四节不变）；不得为了互动而拔高结论或强塞预测年份。
- **`cta_plan[].at_segment` 语义（P10-1 钉死）**：**0-based** 段落下标（`0` = 第一段），
  有效范围 `0..segments.length-1`；越界或非整数由 retention 机械层报结构违规码
  `CTA_AT_SEGMENT_OUT_OF_RANGE` / `CTA_AT_SEGMENT_INVALID`（不计 FAIL，但须修正）。

### 2.4 留存不得越界（红线优先）

明确禁止"为了留存"而：制造假钩子（承诺后不兑现）、夸大证据结论、把推测写成事实、
制造不存在的因果、删除关键限定词、为了让反转成立而篡改数字或时间线。
**留存是优化目标，不是事实的来源。**

## 三、v1 / v2 保留的有效规则（**不退化**，继续遵守）

### 3.1 v1 保留条款

- 信息密度高，但不写成论文；有明确个人观点；从具体问题切入更大的问题；逻辑层层推进。
- 语言自然，像一个人在认真跟观众聊天；不卖弄知识；不堆砌华丽辞藻。
- 幽默服务于内容（事实本身的荒诞感/前后反差/一本正经的吐槽/轻微自嘲）；不强行玩梗。
- 严格区分【事实】【推断】【观点】【争议】；不把推测写成事实；资料不足就明说不确定。
- 每个段落尽量承担一个明确功能；不出现"为凑字数而存在的段落"。
- **不复制任何具体创作者的固定句子、口头禅、段落结构；学的是"写作机制"，不是具体文本。**

### 3.2 反 AI 腔：不允许模板驱动

- 不允许"咱们聊聊……""其实啊……""是不是有点意思～""关于这个命题，有一个你可能没想过的答案～""进入下一部分……""综合现有证据……可以谨慎作答"这类固定句式重复出现。
- **不允许用另一套固定模板替换旧模板。**
- 每一句的写法由**内容本身**决定，不由段落位置决定。

### 3.3 风格目标

> 【一个真正懂科技、查过资料、自己想过这个问题的人，在 B站认真把一个复杂问题讲明白。】

有观点，但不武断；有悬念，但不故弄玄虚；有数据，但不堆数据。
有口语感，但不油腻；有逻辑，但不论文腔；有节奏，但不模板化；有情绪，但不表演。

### 3.4 问题意识驱动全文

提出问题 → 观众形成第一印象 → 给出事实 → 出现反差 → 进一步追问 → 引入新证据 →
修正判断 → 形成更准确的答案。每一个章节都必须服务于核心问题。

### 3.5 不允许机械章节化

禁止频繁使用："接下来我们来看""进入下一部分""首先……其次……最后……""下面我们继续"。
章节之间通过**逻辑**自然过渡；逻辑足够自然时，不需要过渡句。
**（v3 补充）** 章节之间必须有**钩子衔接**：本章结尾要么给出下一章的真正问题，
要么留下一个待兑现的悬念；连续 90 秒没有信息增量点视为**结构缺陷**。

### 3.6 严格控制固定口头禅

以下表达不是绝对禁用，但不得形成模板、不得在不同章节机械重复：咱们聊聊 / 其实啊 /
是不是很有意思 / 你有没有想过 / 你可能没想到 / 值得注意的是 / 换句话说 / 这意味着 /
可以说 / 从某种意义上来说 / 综合来看 / 归根结底 / 简单来说。
**删除后不影响逻辑的，直接删除。**

### 3.7 反问句必须有信息价值

禁止为了"视频感"连续使用"是不是很有意思？""你有没有想过？""这是不是很神奇？"。
反问只有在能真正改变观众认知时才使用。

### 3.8 不为了凑时长增加废话

10 分钟视频 ≠ 人为制造 10 分钟文字。20 秒能讲清的事实不扩成 40 秒。
值得深入的问题，用 事实→案例→数据→解释→对比→限制→推论 自然加深，而不是堆形容词和总结句。

### 3.9 口语化，但不低幼化

禁止："兄弟们！""这也太离谱了！""家人们谁懂啊！"等营销腔；也不过度文艺。
目标：自然、克制、清楚、有一点个人判断的中文口语。

### 3.10 句式必须自然变化

避免同一句式连续出现（"它可以……它可以……"）；不同章节根据内容决定节奏。

### 3.11 必须允许"思考过程感"

允许："但这里有一个问题。""如果只看到这一步，很容易得出错误结论。""真正麻烦的其实在后面。"
——服务于推理，而非作为模板。

### 3.12 长视频叙事原则（8-15 分钟）

核心问题 → 建立直觉 → 挑战直觉 → 事实与证据 → 第一次阶段性判断 → 发现新问题 →
深入拆解 → 多因素互连 → 重新定义问题 → 最终结论。（叙事原则，不是模板。）

### 3.13 开头 / 中段 / 结尾

- **开头**：前 20-40 秒进入问题并制造认知冲突（**同时**满足 2.1 的 Hook 纪律）。
- **中段**：每个重要段落至少完成一个新事实 / 推翻错误直觉 / 引入关键证据 / 解释因果 /
  建立前后联系 / 提出新问题 / 缩小答案范围 / 修正前面的判断；同时满足"每 60-90 秒一个
  信息增量点"。
- **结尾**：不重复全文；回答"我们现在究竟知道了什么""为什么答案会是这样"；
  若问题没有可靠确定答案，明确解释为什么无法确定、不确定性来自哪里、未来什么变化会改变判断。
  结尾留下的是**经过推理得到的观点**，不是漂亮口号；并遵守 2.3 的 CTA 纪律。

### 3.14 事实与 Evidence 优先级（**红线，不可违反**）

文风永远服从事实。不得为了叙事效果：编造事实、擅自增加数字、把推测写成事实、
删除关键限定词、扩大 Evidence 结论、制造不存在的因果、为了结尾漂亮而强行预测年份。
若 Evidence 只支持"可能 / 目前仍在探索 / 尚无可靠答案"，必须保留这种不确定性。
**同理适用于留存技巧**：不得为了让观众留下而承诺事实不支持的结论（见 2.4）。

### 3.15 AI 味自检（每次生成后强制执行）

1. 是否存在连续重复句式？
2. 是否大量重复相同过渡句？
3. 是否存在机械章节模板？
4. 是否存在无意义反问？
5. 是否存在无意义排比？
6. 是否存在空泛总结？
7. 是否存在为凑时长而增加的内容？
8. 是否存在明显 AI 套话？
9. 是否像人在说话？
10. 是否存在 Evidence 为叙事效果被改变的情况？

**v3 追加（留存自检，同样强制执行）：**

11. 前 40 秒是否给出真正的认知冲突？
12. 是否每 60-90 秒有一个信息增量点 / 悬念 / 反转（`retention_device` 是否名副其实）？
13. `emotion_beat` 是否出现连续 3 个同类？
14. CTA 是否为 1-2 处、是否与内容强绑定、是否出现裸话术？
15. 是否存在假钩子（承诺未兑现）或为留存而夸大？

发现问题 → 优先重写问题段落，而不是替换几个词。

### 3.16 与 2.x / 3.x 架构的关系

本规范是 Creator Style 层升级。不得破坏：Truth/Evidence、Research Brief、Content Plan、
Blueprint、Evidence 引用、Visual Planning、Cost Calibration、Production Entry、Provenance、
QA/Regression、2.x 冻结边界，以及 Phase 6/7 的既有门禁与不可变快照。

**Style 只能改变"如何表达"，不能改变"事实是什么"。**
**v3 附加**：`emotion_beat` / `retention_device` / `cta_plan` / `hook_map` 是**元数据**，
只用于结构核验与后续 critic，**绝不进入旁白文本、字幕、发布稿或元数据正文**。

## 四、梗与人味（v3.1 追加，2026-10-20）

> 背景：全工程检索 `梗/幽默/joke/humor/punchline` 仅命中两处平台画像注释——
> **本系统没有梗的生产者**。真正的人味只能由**人工审稿**注入，本节只负责
> "别把人工注入的东西写跑偏"。

### 4.1 三个入口

| 入口 | 命令 | 说明 |
|---|---|---|
| 导出审稿稿 | `run.py script-review <pid>` | 每段一行（`@@Sxx`）+ 字数预算 + 节拍 + 5 问 |
| 回填 | `run.py script-apply <pid> --file … --checklist 11111` | 校验后写 `media/script_review.json`；`redo` 后**人工稿优先于 LLM** |
| 弹药库 | `config/humor_pack.md` | 句式模板 / 世俗类比 / 数字人话 / 口语连接 / 红线 |

### 4.2 五条硬规则

1. **数字后面必须跟"人话翻译"**（humor_pack §三）。没有"所以呢"的数字，删掉或换掉。
2. **抽象概念必须紧跟一个世俗类比**（§二），不用技术词解释技术词。
3. **每段至少一个"具体"**：人物、地点、时间、物件、数字——四选一。
4. **梗只加在解释层，不加在事实层**：医疗结论、数据句、来源句、人名指控一律不许玩梗。
5. **禁用公文腔**：`综上所述 / 值得注意的是 / 不难发现 / 具有重要意义 / 在当今时代 / 众所周知`
   —— 出现即判 AI 味（`script-review` 会自动告警）。

### 4.3 审稿 5 问（`--checklist` 顺序）

1. 有没有一个**具体的人**（有名字/身份/处境）？
2. 有没有**一句能被截图的话**（≤20 字、有态度）？
3. 有没有**一个反常识**（与常见认知相反且站得住）？
4. 有没有**一个世俗类比**？
5. 结尾**回扣了开头**吗？

> 答"否"的条目不是文艺批评，是这一稿的欠账——写进 `--notes`，下一稿补。
