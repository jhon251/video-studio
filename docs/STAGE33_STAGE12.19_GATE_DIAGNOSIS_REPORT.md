## 3. Gate=0 主要原因判定(问题 3)

**已证明(有 trace 证据):**
1. **Gate 判断深度不足是主导结构问题**:240 判定 vs 1253 未判(每拍仅见池的 16%);决定性证据:**40 拍中 33 拍(82.5%)的"V1 全池最优候选"根本不在 gate 判定的 6 个切片内**——gate 从未见过按冻结 V1 标准最好的候选;
2. **池不缺视觉素材**:IMG 96.8%、池均 37.3,排除"无图可选";
3. **12.13 的池顶修复生效**:已判理由中 off_topic 占比从 12.12 的 70.2% 降至 **42.5%**(102/240)——gate 现在看到的大多不是垃圾。

**INSUFFICIENT_EVIDENCE(严格区分):**
1. 其余 57.5% 非无关拒绝(other 107 / era 26 / abstract 5)是"正确严格"还是"过严",文本理由无法定性(需 LLM 重判,本阶段禁止);
2. **178 个 V1-hidden 未判候选若被 gate 判定,KEEP 率未知**——V1 分数 ≠ gate 判定(12.16 已证 V1 高分可被 CV-2 否),只能证明"存在从未曝光的高排位候选",不能证明"曝光即通过";
3. 7/40 拍 gate 已判过 V1 最优候选并拒绝——这 7 拍是"gate 见过最好的仍全拒",深度扩大对其**无**理论收益(证据:V1 最优已在内)。

## 5. 结论与边界

- Gate=0 的两大可证明原因:**①深度 6 只覆盖池的 16%,82.5% 的拍存在从未曝光的 V1 最优候选;②已判切片中仍有 42.5% 真无关**(检索池中位以下部分)——前者是 gate 层深度问题,后者是池深位质量问题的残余;
- **INSUFFICIENT_EVIDENCE**:曝光后 KEEP 率、非无关拒绝的正确率——两者都需要 gate LLM 受控重跑(本阶段禁止);
- 与 CV-2 深度线(12.16-12.18,25 调用 +10 素材)对照:gate 层面对的未曝光候选规模(178 vs 42)大一个量级,但**无已证明获胜者**,实验前必须明确这是"结构性存在"而非"已证明可用";
- 本阶段未实施 Gate Top-N、未改任何 prompt/depth/threshold/规则。
