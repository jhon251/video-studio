## 4. 唯一推荐新路线:授权 key 制图库接入(Pexels/Pixabay)+ 双臂解耦实验

**为什么是它**:第 2 节的否定清单表明,管线内一切杠杆(Query/Gate/V1/CV-2 深度)已测尽或关闭;58 empty 的主导成因是**候选池里没有可判定的照片形态素材**(域稀缺 + PDF 形态 + 排序掩埋)。唯一能直接增加"新形态覆盖"的杠杆是引入覆盖居家/办公/城市生活照的 key 图库——**它解决的是素材覆盖,不是筛选效率**(12.21 已区分;12.20 证明的筛选成本问题与之正交)。12.14 的失败在域错配,不在"第二源"模式本身;该模式的工程契约(独立适配器 → 同一 Candidate Contract → 冻结 Gate→V1→CV-2)已被验证可用。

**前置依赖(用户决策)**:提供 PEXELS_API_KEY 或 PIXABAY_API_KEY(Pexels 免费层 200 req/h 足够;许可条款允许署名使用)。

**最小 A/B 实验定义(12.23 提案,未实施)**:
- **范围 14 拍**:5 hook/居家(S01-B01/B02/B03、S31-B02 + 1)、5 办公/池耗尽(kept=1 或 top-3 败)、2 最近 ok 金丝雀(S23-B02、S27-B01,防回归)、2 池漂移对照;
