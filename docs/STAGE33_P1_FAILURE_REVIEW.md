## 一、抖动诊断（Motion Integrity Audit，逐镜实证）

### 1.1 测量方法
- 对每个 P1 beat clip、每个 legacy 镜、两个最终成片，逐帧抽取 480×270 灰度帧；
- 10fps 全量扫描（25 beats + 20 legacy 镜 + 2 成片）+ 25fps 帧级复核（6 个代表样本）；
- 指标：帧间平均绝对位移（mean）、位移标准差（std）、尖峰数（jerk）、方向反转数（wobble）。完整数据：`output/stage33/diag/motion_audit.json/.md`。

### 1.2 帧级铁证（25fps 位移序列，前 40 帧）
| 样本 | 位移序列特征 | 判定 |
|---|---|---|
| **B011 PAN_V 文字卡** | `0.0 / 1.84 / 0.0 / 1.84 …` 完美交替 | **1px 步进闪烁**：每 3 帧跳 1 像素，文字边缘可见顿挫 |
| **B003 HOLD_MICRO 图形** | `1.7→0.01→1.09→0.0→0.39→…→2.16 尖峰` 不规则脉冲 | **随机脉冲抖动**：正弦微动+取整，不可预测的 1–2px 跳动 |
| **B016 PULL_OUT 图形** | `1.45→0.01→0.99→0.0→…→2.13` 同类脉冲 | 同上 |
| **B004 PUSH_IN 照片** | `2.07 平台 + 5.4/7.0 尖峰 + 0.05 低谷` 锯齿 | 浮点 zoom 取整的"平台-跳变"模式（照片上不易察觉） |
| **legacy S01 静止卡** | `0.0 ×40`（全零） | legacy 文字卡从不抖动 |
| **legacy S04 照片 Ken Burns** | `2.98/1.89 交替 + 0.2 低谷` | 同类取整锯齿，但只在有机照片纹理上 → 人眼无感 |

### 1.3 逐镜结论（回答 5 个问题）
1. **哪些镜有肉眼可见抖动**：全部 P1 图形/文字卡 beat（B001–B003、B006、B011/B012、B015–B025 中的图形类），最严重 = B003/B011/B012/B015/B016/B018/B020–B023（25fps 复核中的脉冲与步进模式）；素材照片 beat（B004/B005/B008–B010/B013/B014）存在同源锯齿但幅度小、纹理掩盖，观感轻微。
2. **抖动来源（定位到具体参数）**：**Stage 3.3 executor 的 zoompan 运动实现**（`expander._motion_params` 生成的参数串），三型：
   - `HOLD_MICRO: z='1.004+0.004*sin(on*0.06)'` → 非单调正弦 + 整数取整 → 随机脉冲抖动（根因 #1）；
   - `PAN_H/PAN_V: x/y='…*on/N'` 浮点位移 ~0.5px/帧 → 取整为 0/1px 交替 → 文字边缘步进闪烁（根因 #2，B011 铁证）；
   - `SLOW_PUSH_IN/PULL_OUT: z='min(1.0±k*on/N,…)'` 浮点缩放 → 平台-跳变锯齿（根因 #3）。
3. **与素材自身/scale/crop/编码/concat/字幕无关**：legacy 同素材、同编码、同字幕链无抖动投诉；legacy 静止卡 delta=0。
4. **legacy 是否同样抖动**：文字卡完全静止（0 抖动）；照片 Ken Burns 有同源取整锯齿但**不可见**。**抖动是 P1 新增的可见缺陷**——根因是把"照片上无感的浮点运动实现"直接用到了"文字/图形锐边上"。
5. **定性**：P1 的运动实现 = **亚像素浮点轨迹 + ffmpeg zoompan 整数化**，对锐边内容必然产生闪烁。宁可 HOLD 也不要这种运动。

## 二、Failure Root-Cause Review

### A. 为什么机器指标改善，人眼完全没有感觉？

| 指标 | 机器口径 | 人眼实际 |
|---|---|---|
| TEXT_CARD 45%→12% | 档位标签从 TEXT_CARD 变 SELF_CREATED_GRAPHIC | 深色底+白字卡 变成了 深色底+彩字图形卡——**观感同构**：仍是"全屏深底+整句文字" |
| 18 张 graphic | 图形文件数 | 每张都是"全句文字排版"，等于换皮文字卡 |
| 2 个真实视频 | 素材类型数 | 只出现在 2 镜，且其中 S20 延时视频本身很暗（luma≈15） |
| motion 22/25 | 有运动的比例 | 20/25 是 PUSH/HOLD——4~5 秒内 5% 缩放在感知上≈静止，还引入了可见抖动 |
| motif / climax / arc | plan 里的符号 | 未转成画面层可感知差异：climax 只是一张安静图形卡 + intensity 标签 |

**结论**：机器指标度量的是 plan 的"多样性计数"（类型数、占比、是否存在），人眼感知的是"单画面质感 + 连续性 + 焦点管理"。两者之间**没有因果桥**——P1 没有任何指标度量"观众注意力被如何管理"。指标改善 ≠ 设计改善。

### B. 逐镜抽样：模板驱动问题（标准：删掉模板名，剪辑师能否理解画面为何这样设计）

| 镜 | P1 决策 | 剪辑师能否自证设计理由 |
|---|---|---|
| S01 | 图形卡+整句文字+DOWN 推入 | ✗ 字幕已有全文，卡重复全文；运动与"褪色"无因果 |
| S06 | 海温视频+稳定构图 | ✓ 数据句看动态数据（P1 少数的好决策） |
| S07 | 海洋热含量图 | ✓ 数据被看见 |
| S10 | 两张全文卡+UP/DOWN | △ 方向语义成立，但仍是全文卡（"绑/种"动作没被视觉化） |
| S13 | 图形卡+PAN_V | ✗ "饭碗消失"的因果/后果没有视觉化 |
| S14 | **有合格小丑鱼素材却选图形** | ✗ 无法解释为何不用素材 |
| S16 | SPLIT_H 对比分栏 | ✓ "不是…而是"被并置（P1 最好的一镜） |
| S18 | 高潮=安静图形卡 | ✗ "生死/十年选择"的张力完全缺失 |
| S20 | 延时视频+拉远收束 | ✓ |

**抽样结论：9 镜中 4 能自证 / 1 半 / 4 不能。** 失败镜的共同点：答案都是"因为这个 beat 类型是 X，所以用了模板 Y"——**这正是"LLM 给模板选参数"，不是导演。**

### C. 为什么出现"PPT 感"（8 条根因）
1. **全文卡**：字幕已经显示整句，卡上又放整句 → 双份文字、零信息增量、必像 PPT；
2. **深色满屏卡**：无层次（只有 bg+字），无 foreground/midground/background；
3. **运动无信息**：PUSH/HOLD 不改变"信息如何呈现"，只为满足"有运动"（且抖动）；
4. **FULL_BLEED 连排**：素材段满屏构图 4 连，无景别/焦点变化；
5. **焦点不管理**：观众不知道看哪里（大字/字幕/素材三处竞争）；
6. **镜头间无关系**：图形卡↔素材图之间无延续元素，拼接感；
7. **无节拍**：无 BGM，视觉节奏只能靠 4–6 秒匀速缩放，无高潮释放的物理表现；
8. **素材-图形切换无逻辑**：S14 有素材却上图形，S06 上视频——选型理由在 plan 里，不在画面里。

## 三、Motion Integrity Audit 规范（v3 起执行）

- 机器预检指标：帧间位移序列（25fps 全检）、位移方差、尖峰（jerk）、方向反转、**单调性**、**整数步进性**（每帧位移 ∈ {0} ∪ [1, N]px 且方向不反）；
- 铁律：`natural > meaningful > smooth > restrained`；**HOLD = 绝对静止（0 位移）**；
- 禁止清单（机器强制）：正弦微动、亚像素平移（<1px/帧浮点轨迹）、浮点 zoom 表达式、非单调轨迹、无理由的方向反转；
- 渲染方案（v3 executor）：**帧级整数运动渲染**——Python 预生成每帧整数裁剪矩形（单调、整数步进、三段缓动），PIL 逐帧裁剪 → ffmpeg 编码；**彻底废除 zoompan 做镜头运动**；
- 验收口径：jitter=0（25fps 全片检测），任何脉冲/步进闪烁 → Gate FAIL。

## 四、剪映"文字成视频"对比分析（为什么它更自然，即使不懂导演逻辑）

| 角度 | 剪映文字成视频 | 我们的 P1 | 差距本质 |
|---|---|---|---|
| 镜头选择 | 每句一个"情绪/氛围"素材，不追求事实精确 | 试图语义精确，素材不足就图形卡 | 抽象度匹配不足 |
| 画面层次 | 素材+动态关键词+统一滤镜=天然三层 | 深色底+整句字=两层还重复 | 无层次 |
| 节奏 | 音乐节拍驱动，切点均匀 | 无 BGM，切点=句子，节奏平 | 无节拍锚点 |
| 动态幅度 | 文字动画细腻（专业缓动曲线，无子像素抖动） | zoompan 浮点取整抖动 | 渲染管线质量差 |
| 构图 | 素材为主体，文字为辅 | 文字是主体，素材为辅（或没有） | 主次颠倒 |
| 视觉焦点 | 每句一个焦点（大关键词） | 三处文字竞争 | 焦点不管理 |
| 镜头连续性 | 统一滤镜/字体/版式 | 图形↔素材切换无延续 | 无一致性 |
| 信息密度 | 低（字幕+一个关键词） | 高（卡上全文+字幕） | 过度信息 |
| 模板克制 | 一套模板用全片 | 六档表达+14 角色+8 构图混用 | 一致性 |
| 素材利用 | 大素材库，画面多样 | 素材少且被图形替代 | 供给差距 |

**结论：剪映赢在"低信息密度 + 节奏包装 + 渲染平滑 + 全片克制统一"，不是赢在模板数量。** 我们要学的不是更多模板，而是：**每句只给一个视觉焦点、画面分层、运动平滑（或干脆静止）、全片一套视觉语言。**

## 五、Stage 3.3 v3 Architecture Proposal（草案，待裁决，不实现）

### 5.1 核心转变
> **Director 的决策单元从"选哪个模板"改为"产出视觉命题（Visual Statement）"。**
> 每个 beat 必须能回答：**"我希望观众这一秒看哪里、理解什么关系、产生什么认知变化，以及为什么这个视觉形式比另一种更好。"**

### 5.2 决策链（LLM 输出，模板枚举不再出现在输出中）
```
narrative_intent          这一句在叙事里做什么（建立/递进/对照/强调/收束）
viewer_attention_target   观众该看哪（锚点词/数字/对象/关系）+ 注意力路径（先看哪→后看哪）
visual_metaphor           用什么可感形式承载（素材直证/数字体量感/对比并置/空间示意/过程动势）
                          ——必须 grounded：口播原文/证据可溯，禁止发明
visual_evidence           支撑元素（白名单素材 或 原文数字/关键词）
spatial_composition       分层构图：background(氛围)/midground(主体)/foreground(锚点词)
shot_language             机位/景别语义（推近=聚焦、拉远=揭示、横移=推进）；每镜头只允许一个动作意图
temporal_behavior         时序脚本：进入/停留/揭示/退出（整数帧级缓动，或无）
relationship_to_prev     延续元素（色/运动方向/主体回声）+ 变化元素（景别/焦点）
relationship_to_next      同上
graphic_layer             仅当有信息增量：锚点词/数字/示意，**字数上限 12 字**
audio_relationship        与 VO 关系（静默/强调/留白），P3 生效
director_note             ≤80 字导演阐述（人工可直接审计"为什么这样设计"）
```

### 5.3 v3 关键机制（回答 11 问）
1. **Director 负责什么**：每个 beat 的视觉命题与理由（注意力管理），不是模板选择；
2. **LLM 输出什么**：§5.2 命题字段 + director_note；模板/运动枚举从输出中移除（降级为 realizer 内部原语）；
3. **Validator 验证什么**：三层——安全层（P1 全保留：白名单/Truth/阈值/稿文/数字）+ 结构层（命题要素齐全、attention_target 存在于画面元素、metaphor grounded、字量 ≤12、单动作意图、前后关系非空）+ 完整性层（§三 运动预检：单调/整数步进/静止-静止）；
4. **Executor 执行什么**：realizer——分层合成（bg/mg/fg）+ 帧级整数运动渲染（PIL 逐帧 → ffmpeg），**废除 zoompan**；时序脚本执行；
5. **如何避免"会动的 PPT"**：三规则——卡片只放锚点词（全文交给字幕）；每个画面必须 ≥1 个"注意力事件"（数字入画/焦点转移/层次揭示）；图形 beat 也有进入→停留→退出时序；
6. **如何避免莫名其妙 motion**：运动必须绑定注意力转移理由；HOLD=真静止；废除正弦/亚像素/浮点 zoom；运动幅度服从"是否被感知"（<0.5%/s 或不可感知的运动一律禁止）；
7. **如何让镜头之间产生关系**：强制延续三件套之一（色延续/运动方向延续/主体回声）+ 一个变化项（景别/焦点），Validator 结构层检查；
8. **如何让节奏形成高潮/释放**：视觉复杂度曲线（层数×对比度×运动幅度）随 arc 变化；高潮=复杂度峰值+单次显著动作；释放=去层+静止收束；
9. **如何处理无素材句**：优先"注意力锚点卡"（关键词+层次+时序），其次示意图，全文卡**废止**；全部 grounded；
10. **TEXT_CARD 如何成为最后手段**：字量 ≤12 + 必须分层 + 时序脚本 + 连续 ≤2；且"素材不足≠自动卡"规则保留；
11. **如何评价视觉表达质量**：机器只测 integrity（jitter=0/轨迹单调/层级存在/字量合规）+ 技术 QC；**表达质量 100% 由人工裁决**（8 维评分 + 5 层达成度：技术正确→表达意图→镜头关系→节奏服务叙事→无 AI 拼接感；第 5 层为成败线）。

### 5.4 保留 / 废弃 / 重构
| 类别 | 内容 |
|---|---|
| **保留** | sanitizer 白名单；Validator 安全层（truth/rights/threshold/稿文/数字/素材一致性）；split_n 文本确定性落地；表达阶梯概念（TEXT_CARD 定义重做）；legacy 零改动执行复用 + 对照评估流程；8 维人工评分；盲测协议（P4）；LLM→规则回退链；按镜重试/回退机制 |
| **废弃** | zoompan 全部运动实现（抖动根源）；HOLD_MICRO 正弦微动；"motion 类型 ≥4"等数量型 Gate；模板/角色枚举作为 LLM 输出字段；全文文字卡；FULL_BLEED 默认构图；"多样性计数"型机器指标作为通过依据 |
| **重构** | Director 输出模型（视觉命题式）；executor 渲染管线（帧级整数 PIL 管线）；graphics（锚点词卡+分层+时序）；Validator（+结构层+完整性层）；评价体系（质量审计替代数量审计） |
