## 三、标注标准（truth_label 语义定义，V2.1 判定必须遵守）

1. **判定对象**：Evidence 是否真正讨论 Claim 的主体、谓词、对象及关键限定词。
   "出现同一个词"≠支持；关键词只作定位，不作判定。
2. **DIRECT_SUPPORT**：Evidence 完整背书命题的主体+谓词+对象，且关键限定词
   （第一/最大/唯一/目前/首次、约/大约、可能、基本共识、永远/必然、数字/年份/
   机构名）不缺失、不冲突。
3. **PARTIAL_SUPPORT**：Evidence 背书部分要素（如主体+数字但缺"最大"限定；
   同主题讨论但数字不完全一致；相邻领域）。
4. **CONTEXT_ONLY**：仅个别词面出现（≤ 4 个词元），不构成对命题的讨论。
   不得参与结论综合。
5. **IRRELEVANT**：无主题关系（含关键词高度重叠但同形异义/不同实体的页面）。
   不得参与结论综合。
6. **CONTRADICTS（新增反驳资格判断）**：
   - 问句/反问句不得因页面出现"不是/并非"等否定词而判 CONTRADICTS；
   - 定义句不得被普通事实页面判"被反驳"；
   - Evidence 必须对 Claim 的可验证命题构成真实的否定/矛盾（同谓词、同对象、
     冲突的限定词/数字/结论）；
   - 仅语境不同（影视叙事 vs 现实报道、不同实体同名）→ CONTEXT_ONLY 或 IRRELEVANT。
7. **独立性**：两条 Evidence 是否真正独立、是否支持同一命题，必须被显式判断；
   禁止"2 条相关证据 = 自动 Confirmed"。

## 五、测试设计

文件：`tests/evidence_regression_test.py`。

- **现在（阶段 0）**：仅校验数据集本身——数量/字段/真实来源数据库比对/
  伪冲突对照组一致性/词面重叠性质。该测试当前全绿，且**不调用任何生产判定逻辑**。
- **语义层实现后（阶段 1+）**：追加核心断言（测试文件中已留占位注释）：

  ```python
  from video_studio.tools.semantic_judge import judge_support   # 待实现
  hits = sum(1 for s in samples
             if judge_support(s["claim_text"], s["evidence"]) == s["truth_label"])
  check("全 50 样本 truth_label 全中", hits == 50)
  ```

  **通过标准：50/50。任何 1 条不符 → 语义层不得合并，全量回归失败。**
  集成位置：全量回归套件（smoke/pipeline/schema/agents/factcheck/strip/hitl/
  search_quality + evidence_regression）中最先运行本套件。

## 六、维护规则

- 禁止修改任何样本的 claim_text / evidence.text / truth_label（除非经用户确认的
  标注错误，并记录变更原因）。
- 新增样本只能来自真实运行结果（新轮次数据库或同查询补采），必须注明 provenance。
- 每轮语义修复前后都跑本套件，报告命中数变化。
