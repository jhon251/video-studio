# Stage 3.3 V3 Green-Screen Failure Analysis（Visual Failure Analysis · 只诊断）

> 裁决背景：V3-M3 R2 技术层通过（**P1 抖动已消失**），但人工观看发现"绿幕人物/绿幕素材 + 文字"画面。本轮只诊断，不写代码、不重渲染、不改 plan/Gate/阈值、不进 P2。

## 0. 机器侧先证：literal 绿幕不存在，"绿幕感"是另一种东西

逐 beat 全分辨率扫描 22 个 material beat 的绿色主导像素占比：

- **green_frac 全部 ≈ 0**（范围 0.000–0.084；S14 小丑鱼照片的 0.084 是海葵的自然绿色）；
- 真正绿幕素材的绿色占比应为 0.3–0.6 → **3.1.4 白名单中不存在绿幕素材**。

因此人工观感中的"绿幕人物+文字" = **人物类素材（电影剧照/油画/纪实照片）被全屏铺底 + 大字锚点叠加 + 字幕**构成的视觉拼贴——它长得像"抠像人物+文字"，但不是绿幕技术问题。**问题名应改为"人物素材被当作背景使用"。**

## 2. 区分两类问题（A 执行方式错 / B 选择错）

- **B 类（选择错，主因）**：
  - **S03**：为"下到十米深、大片雪白珊瑚骨架"选择 1957 电影剧照（sem 仅 50.0）——素材与句子语义错位（剧照≠珊瑚骨架），这是**选择错误**，不是执行错误；
  - **S19**：为"看见水下另一个世界"选择"沙滩孩子"照片——孩子相关于"海边小孩"半句，但与"水下世界"无关；素材只匹配了半句。
- **A 类（执行错，次因）**：S12（渔民油画确实匹配"渔民的网掠过水面"）——素材有价值，但"全屏油画 + 句子片段大字"把它变成了宣传画；若把油画作为**主体置于一侧、给海面空间关系、锚点只用"网"**，观感完全不同。

| 镜 | 删掉人物素材留背景 | 删掉文字留人物 | 换成自然照片/视频/纯隐喻是否更高级 |
|---|---|---|---|
| S03 | 观众损失语境（只剩色块） | 只剩一张旧电影剧照，无法理解"十米珊瑚骨架" | **是**：有真实珊瑚骨架图/下潜视频会明显更好；无素材时应走"深度数字+空间示意"隐喻而非硬用剧照 → **GREENSCREEN_DECISION_UNJUSTIFIED** |
| S12 | 损失"渔民"主体 | 油画自身能传达"渔民收网"，但锚点"掠过"的空间动作丢失 | **是**：油画作主体+海面层次，或真实渔民视频 |
| S19 | 损失人物情绪 | 照片能传达"孩子+海边"，但"水下世界"完全丢失 | **是**：孩子近景+水下分屏隐喻更准确 |

**判定**：S03 = GREENSCREEN_DECISION_UNJUSTIFIED（选择+执行双重错误）；S12/S19 = 素材部分可用但执行方式不成立（全屏+文字）。

## 4. 是否发生"伪视觉命题"（本次最重要诊断）

**部分成立，且与素材供给直接耦合**：

- **LLM 镜**（S04/S05/S09/S11/S14）：命题真实（attention_target 是真关键词、分层有职责、理由可自证）——但其中 S04 锚点"穿过"、S05"不是/而是"是**弱连接词**，仍非内容锚点；
- **回退镜**（S03/S06/S07/S12/S17/S19/S20 等 12 个 beats）：statement 是规则模板句（"以原文词为唯一焦点做最小构图演绎"），锚点退化为 6 字句子片段，director_note 为模板文——**这些不是视觉命题，是"文字卡换皮"**。9/20 镜回退 + 片段锚点 = V3 在素材贫瘠区仍然退化为文字依赖。

**结论：V3 的 Statement 架构在"有合适素材"的镜上成立；在"素材贫瘠/无素材"的镜上，回退路径重新制造了 P1 式退化（只不过从全文卡变成了片段锚点卡）。问题不在架构命名，在于回退规划器与 Director 都没有"没有好素材时就不放人物/不放文字"的判断力。**

## 5. 什么时候绿幕/人物素材真正有价值（不搞一刀切禁令）

| 允许条件 | Coral 现状 |
|---|---|
| 人物是叙事主体 | S12 渔民（勉强）/ S19 孩子（半句）——其余无 |
| 人物与背景有空间关系 | **全部缺失**（都是全屏平铺） |
| 人物承担尺度/动作/情绪 | S12 收网动作勉强 |
| 人物改变注意力路径 | 无（人物被当背景，注意力被锚点字抢占） |
| 抠像/人物是不可替代的视觉证据 | 无 |

**不建议"绿幕禁令"**（literal 绿幕不存在）；应立的是**"人物素材构图规则"**：人物素材禁止作全屏文字背景，必须作为主体并配空间关系/尺度参照——但这属于实现阶段的事，本轮只诊断。

## 7. 核心问题与根因判定（8 候选逐一检查）

> 为什么 V3 的 Visual Statement 架构仍然没有让 Director 自然地产生"像专业剪辑师一样选择画面"的结果？

| 候选根因 | 判定 | 证据 |
|---|---|---|
| 1 素材供给不足 | **成立（主因之一）** | S03 的 whitelist 里最好的素材是 sem=50.0 的 1957 电影剧照——根本没有珊瑚骨架画面可选 |
| 2 素材理解不足 | **成立（主因之一）** | 3.1.4 只给 sem 分 + 文本描述，不给"人物/剧照/油画/照片/景别"等视觉类型 → Director 不知道 S03 是旧电影人物剧照、S12 是油画，一律当"相关图片"全屏处理 |
| 3 Director 视觉语言先验不足 | 成立（次因） | 3B 模型的最省力输出=全屏素材+居中大字；没有"人物作主体+空间关系"的镜头语言 |
| 4 Statement→Executor 表达能力不足 | 部分成立 | v3 只有 9 种行为，无"主体位置/尺度参照/空间关系"参数化——即使 Director 想表达也做不到 |
| 5 evaluation feedback 未进入 Director | 成立 | 两轮人工反馈（P1 抖动/PPT、V3 绿幕感）从未回灌给生成循环，LLM 每次从头生成同样的问题 |

| 7 3.1.4 把选择空间锁死 | 部分成立 | rights/threshold 白名单正确（不该放松），但**候选元数据不含视觉类型信息**，等于让 Director 盲选 |
| 8 其他 | 成立 | 核心真相：**coral 素材库本身质量天花板**——剧照/油画/地图/照片，无一条真实珊瑚礁视频；"巧妇难为无米之炊" |

## 8. 最终判定

**GREENSCREEN_ROOT_CAUSE = 素材理解缺失 × 素材供给不足的复合缺陷（非绿幕技术问题）：**
Director 拿到的候选元数据只有"语义分 + 英文描述"，无法知道"这是一张 1957 电影人物剧照 / 一幅油画 / 一张纪实照片"，因此把人物素材一律当作全屏背景叠字；同时白名单中没有更好的画面可选（S03 最优仅 sem=50 剧照），回退路径又把锚点退化成句子片段——三者叠加，形成人工看到的"绿幕人物+文字"拼贴。**literal 绿幕素材数量为 0（green_frac≈0 实证）。**

**二选一结论：应转向「素材供给 + 视觉理解」能力层，而不是继续在 3.3 决策层内迭代。证据：**

1. **抖动已解决、命题架构已成立**——3.3 决策层在"有合适素材"的镜（S04/S05/S09/S14）产出了真实命题，证明决策层本身不是主要瓶颈；
2. **两轮失败（P1 PPT、V3 绿幕感）的共同根因都在素材侧**：P1=无素材→图形卡流；V3=差素材→人物剧照+文字。迭代第三轮 3.3 决策规则，改变不了"剧照还是剧照"；
3. **素材理解缺失是当前最大盲区**：系统从头到尾没有"看见"过任何素材的画面内容（构图/主体/景别/色调），所有选择基于文本分——这是比"供给不足"更可修复且更优先的能力缺口（本地 MiniLM 已有，缺的是视觉编码器/或至少候选元数据扩展）；
4. **evaluation feedback 缺失**：人工两轮反馈没有进入系统任何一环——这是 3.3 能力层可独立修复项，但单独修复它仍绕不开素材问题。

**建议路径（待裁决，不实现）**：
- 短期（3.3 内、低成本）：候选元数据增加"素材类型/主体/景别"字段（3.1.4 只读包外挂分类器或人工标注）、人物素材构图规则、回退锚点强制 ≤4 字关键词、人工反馈注入 prompt（few-shot 负例）；
- 中期（能力层）：**视觉理解接入**（本地图像编码/CLIP 级模型或分类器 → 候选视觉特征进入 Director 上下文）；
- 长期（供给层）：素材库扩容/真实视频源——决定系统视觉天花板。

**STOP。本轮只诊断，等待裁决：是否接受"转向素材供给+视觉理解能力层"的判定，以及采纳哪条修复路径。**
