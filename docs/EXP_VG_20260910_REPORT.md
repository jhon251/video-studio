## 1. VG1 方法

**完全离线影子重指派**(代码: `audit_20260910_vg/vg1/vg1_shadow.py`; 只读 Run02 artifact):

- **内容身份**: MD5 → dHash 联合聚类(≤6 判同内容, 7–10 保守并入并记录 suspect); 不使用 material_id/路径。全体下载候选(~200 文件)聚为 51 簇 + 6 图表簇
- **EVIDENCE 拍**(64): 本拍候选池内按冻结 CV2 判定(USABLE/CU, fit 降序)选第一个内容全局未用且不与邻拍同内容的候选; 否则转 FALLBACK
- **VIZ 拍**(11): 图表 ≤2 次、使用必须在不同 chapter(=24 拍渲染分部)、不相邻; 违规先换图表池
- **HN/FALLBACK 借用账本**: 每内容 ≤1 个借用者; 与该内容任一已展示时段 start 间隔 ≥60s; 同 chapter 借用 +100 惩罚; 距离最小者胜
- **callback 注册数 = 0**(注册需人工签核, 影子实验取最严格档); **违规级联**: 换池 → HN → 空位卡; 全程无静默重复

## 4. Crop-aware recheck(CV2 原图 PASS → 裁切后异常)

- **CV2 实拍复核**: `vision_call` 对裁切带实判 **被 HTTP 402(额度耗尽, L1_HTTP_API_FAILURE×3)阻塞**——非代码/策略问题。已保存裁切带文件(`vg2/crop_S10-B02.jpg` 等)与调用脚本路径, API 额度恢复后 3 次调用即可补验(S10-B02 crop + S06-B01 crop + 1 对照)

## 8. 失败案例(如实记录)

1. **VG1×VG2 层间缺口(最重要)**: W1-B 的 S29-B03 借用了 r2_S25-B01_0——一张 **UI 截图**("tap to edit")。复用策略只保证"不重复", 不保证内容质量; 该资产被 VG2 正确标记(G2+G5)。**结论: 生产顺序必须是 Integrity Gate 先过滤借用源池, Reuse Policy 再选择**——两道门串联, 不可单开。
2. **S33B 回顾段语义错配**: 零回调注册的严格档下, 结尾"五层阶梯回顾"三连拍被换池为带宽图/读写图/瓶颈图(视觉去重成功, 语义错配)。修复路径: 人工签核后将 S33B 注册为 narrative anchor callback(政策本就允许), 或建设 VIZ 生产能力生成回顾变体图表。
3. **G5/G7 误报超标**(§6): 启发式特征不足以区分"均匀背景"与"拼贴网格"、"角部纹理"与"水印"。
4. **外部资源阻塞**: DeepSeek API 402(额度耗尽)导致 CV2 裁切实判与 CV2 盲评两项增强验证未能执行(均已有降级替代, 见 §4/§5)。

## 10. 推荐最终 Policy(开发基线)

以 `vg1/vg1_shadow.py` 实测版为准, 冻结为预注册规格:

- 内容身份: MD5 → dHash(≤6 同, 7–10 人工带); 一切计数按内容簇
- EVIDENCE: 每拍独立内容; 内容全局唯一(回调需注册 `callback_of`, 注册须人工签核); 不与邻拍同内容
- B-roll/借用: 每内容 ≤1 借用者; 任一内容两次展示 start 间隔 ≥60s; 同 chapter 借用 +100 惩罚; 违规级联 换池→HN(角标)→空位卡
- VIZ: 图表 ≤2 次、跨 chapter、不相邻; 换池顺序=原指派→其余图表; S33B 类回顾段建议注册为 anchor 或等待 VIZ 生产能力
- 前置: Integrity Gate(G0–G4+G8+G9 BLOCK 级; G5–G7 advisory 直至校准)过滤资产与借用源池
- 渲染配套: 竖构图(AR<0.8)强制 contain(或裁切带复核 vis<0.55&shift≥14 → contain); 图表强制无字幕重叠排版与字体预检; MOTION 死代码接驳另行立项
