## 2. 判定:1/5 < 3/5 → `NO_NEXT_STAGE_REQUIRED`

## 3. 结果的机制解读(诚实归因)

1. **冻结链的复合焦点写在 visual_intent 里,CV-2 以它为 focus_hint**。证据核心候选即使语义命中(HIGH),只要不满足原复合场景("空旷广场"/"现代办公室"),仍被判 NOT_USABLE——Stage 17 的诊断被验证到底:瓶颈不是检索,是**冻结的复合焦点模板本身**,而本轮范围明确禁止修改 Query/意图/CV-2。
2. S30-B01 通过的原因恰恰是反例证明:该拍 intent("机器人手臂在工厂流水线工作")与真实工厂机器人画面天然兼容,冻结链立即给出 0.9 USABLE——冻结链有识别真实证据的能力,问题只在个别拍的 intent 模板。
3. S08-B03:诚实障碍是工程性的(pexels 缩略图未持久化),且已有冻结分数并不高于原素材,不强行放行。
4. S30-B01 替换候选已通过冻结链并明显改善,予以**保留记录**;由于整体门槛未达,不进入渲染阶段。若未来授权修改意图模板(新一轮实验),S30-B01 可直接复用本轮验证结论。
