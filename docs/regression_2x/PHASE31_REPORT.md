## 4. 阻断根因：冻结核验度量的**子窗口库覆盖不足**（非素材错配）

### 4.1 素材**确实在屏**（目视 + 数值双证）
- **目视**：`output/p31_probe/frames/S11p2.png` 显示素材原图中的
  「ABSTRACT MATHEMATICS / CONCRETE MATHEMATICS / Transcendental Analysis / Synthetic Geometry」
  分支结构与文字，**确为该素材的推近裁切**（底部叠有字幕「2020年，」）。
- **数值**：对同一成片帧做**手工细网格**搜索（16:9 窗口比例 40%–100% × 9×9 位置）：

| 景 | 冻结 `bank_score` 最优 | **手工细网格最优** |
|---|---|---|
| `S11p2` | 0.2703（scale 0.8，x0 140 / y0 48，1123×632） | **0.6878** @ 比例 **0.72**（x0 246 / y0 96，1010×568） |
| `S13p2` | 0.2846（同上窗口） | **0.7278** @ 比例 **0.72**（同上窗口） |

⇒ **真实呈现窗口**（素材宽度 ≈72%、居中）**完全落在** 16:9 窗口族的可行域内，但其 corr 高达 0.69/0.73。

### 4.2 为什么冻结 bank 取不到该窗口
`core/corr_diagnostics.py`：`BANK_SCALES = (1.0, 0.8, 0.6, 0.45, 0.35)`、`BANK_GRID = 5`。
1. **比例受限**：该素材为 **1404×696（2.02:1）**，而子窗口强制 16:9 ⇒ 可行窗口尺寸
   `h = min(round(w·9/16), H)`。当 `w = round(1404·0.8) = 1123` 时 `h = 632`，但素材高仅 **696**
   ⇒ 实际取到的是 **0.8 宽 × 0.745 高**，**已偏离**真实呈现窗口所需的 ≈0.72 比例。
2. **网格过粗**：`5×5` ⇒ x 步距 `(1404−1123)/4 ≈ 281 px`、y 步距 `(696−632)/4 ≈ 60 px`。
   真实窗口 `x0≈246 / y0≈96` 落在网格点 `(140, 48)` 与 `(421, 144)` **之间**，**取不到**。
⇒ 与本仓**既有登记完全一致**：Phase 17 已记录该素材的**度量伪影**
（`crop_safety 0.0906`、以及「稀疏线稿在 48×48 塌陷」+「运动缩放致画面=子窗口」），
并已建议「**提高分辨率（如 192）重验同一 bank 形式**」而非放宽阈值。
**本阶段未改动任何阈值或口径**（授权禁改）。

### 4.3 与 VLM 语义证据的关系（方向一致）
Phase 28 的 VLM 仲裁对 `S11p2`（corr 0.286）判 **present**、理由为「与素材原图结构一致的分支文字，
属局部裁切呈现」；`S13p2` 同类。⇒ **度量判"低分"、语义判"在屏"**，
两者差异正好落在 §4.2 的度量边界上。
