## 0. 现状断裂（为什么现在做）

5-A～5-G 构建了完整的多模态评估子系统（4-B 文本 / 5-A 单帧 / 5-D 时序 / 5-E 校准 / 5-F Judge），
但评估结果**只存在于独立命令的输出中**（`run.py mm-quality` / `run.py mm-judge`），人工必须
单独运行才能看到。生产报告（`run.py report`）包含项目/任务/产物/成本/素材/成片/响度/署名
共 8 个完整节，**没有任何多模态质量节**。

这意味着：人工在审阅生产报告做出"这条片子好不好、哪里需要改"的决策时，**看不到评估子系统的
任何结论**——60 拍域一致、34 拍 HN 角标、2 处实例粒度分歧、纯色底 fail-closed——这些信息
全部不可见。这是"评估子系统产出"与"人主导决策"之间的可见性断裂。

5-H 补的就是这个断裂：**把 Judge 的最终判定结果以只读咨询方式呈现在生产报告中**，
让人工在审阅成片时能看到每个镜头的质量评估，从而做出有依据的改进决策。

## 1. 5-H 核心能力（一个）

> **生产报告多模态质量咨询节**：`run.py report` 新增一个只读多模态质量咨询节，
> 呈现 Judge 对每个镜头的最终三态判定（MATCH/MISMATCH/UNKNOWN）+ 理由码 +
> R4 的 UNKNOWN 两种语义分型 + R6 的 top-1 一致性解释性指标，
> 让人工在审阅成片时能基于评估子系统的结论做出有依据的改进决策。

（对应 5-F 遗留 R4 + R6 落地；两者是同一报告节的两个展示维度，非独立能力。）

**为什么现在做**：
- 5-A～5-G 评估子系统已完备（32 例真值集、Judge 43/43、三层证据、DoD 12/12）——但产出**不可见**；
- "人主导"要求人工能看到评估结论才能决策——没有可见性就没有人主导；
- 这是 5-F 报告自荐的"值得进入最终产品"项（R4/R6），且是后续一切 Judge-生产集成的**前置条件**
  （人工先看到结论，才能决定是否授权自动化）。

## 2. 目标与非目标

### 目标

1. `run.py report` 新增**多模态质量咨询节**（只读），含：
   - 每镜头最终三态（MATCH/MISMATCH/UNKNOWN）+ 理由码
   - R4：UNKNOWN 两种语义分型（`结构性` = 画面在时间轴上不稳定；`证据不足` = 层间冲突/单层不足）
   - R6：top-1 一致性解释性指标（标注"仅展示，非判据"）
   - 汇总行：域一致 CORRESPONDING 计数 / HN 计数 / UNKNOWN 计数
2. 数据来源：**冻结评估产物**（`--from-calibration` 复用路径），不实时重跑三层
3. 有评估数据时显示；无数据时显示"未评估"（不崩溃、不冒充）
4. 节头部标注"**只读咨询：人工决策依据，非自动阻断**"

### 非目标

- ❌ Judge 接入生产判定链（#49 维持 BY DESIGN：默认关闭、不阻断渲染）
- ❌ 自动拒绝/替换/redo 基于 Judge 判定
- ❌ 修改任何评分逻辑、阈值、判定规则
- ❌ 修改 4-B/5-A/5-D 源码
- ❌ 供给扩池、VIZ、正式生产 Run
- ❌ 进入 5.x Final

## 6. fail-closed / 人工审核边界

- `--mm-advisory` 为**显式开关**（默认关闭），确保不加开关时报告格式向后兼容
- 节头部标注"只读咨询"，尾部标注"人工决策依据，非自动阻断"
- 无评估数据 → 显示"未评估"，不冒充有数据
- 阈值/判定逻辑/评分——零触碰（D8 hash 对账）

## 7. 兼容要求

- `run.py report` 无 `--mm-advisory` 时输出与 5-G 基线**逐字节一致**（向后兼容）
- 评估子系统（mm_quality/mm_judge）sha256 不变（只读消费其输出文件）
- 4.x 链路（Claim/HITL/append-only/许可门禁/旁白完整性/时间轴/响度）零触碰
- 不接生产判定链；不自动换材/选材/redo

## 8. 风险与限制

| 风险 | 缓解 |
|---|---|
| 报告节仅在 `--mm-advisory` 开关下显示 → 人工可能不知道有此功能 | RUNBOOK 新增使用说明 |
| 咨询节数据来自冻结评估产物，非实时重跑 → 如果评估产物过旧则信息滞后 | 报告标注评估时间戳 |
| `--mm-advisory` 开关修改 CLI → 需确认不影响其他命令 | cli.py 只加 argparse 参数，不改其他命令分发 |
