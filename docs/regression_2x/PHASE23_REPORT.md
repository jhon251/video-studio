## 3. P23-3 全文重写管线（DONE，真实 LLM 2 轮）

| 轮 | 状态 | ai_flavor | 字数 | 成本 | 机械校验失败项 |
|---|---|---|---|---|---|
| 1 | **ROLLED_BACK** | 0.2985 | 3350 | $0.01103 | 数字保真（新增 `20`）、实体丢失（`这个猜想`） |
| **2** | **ACCEPTED** | **0.0000** | 3337 | $0.00749 | **无** |

**六项机械校验（第 2 轮全过）**：① 数字保真 ✔（`extra=[] missing=[]`）
② 命名实体保真 ✔ ③ fact_risks **13 条不减少** ✔ ④ retention 机械分 **0.6 → 1.0** ✔
⑤ 字数比 **1.0006**（3337/3339）✔ ⑥ n-gram 守卫 ✔（与参照文本**最长公共 0**）。

**故障与处置（如实登记）**
1. **推理吃满 token**：`deepseek-flash` 首轮 `max_tokens=16384` 全部用于 reasoning、**content 为空**
   （`LLM_REASONING_BUDGET_EXHAUSTED`，与 Phase 8 v3 当年同一现象）⇒ 提高至 **32768** 后正常。
2. **prompt 瘦身**：初版把 style target 全文（含参照例句表）入 prompt ⇒ prompt 5927 tokens。
   改为 `style_digest()` 只投**机制名 + 规则句**（参照例句**不入 prompt**：① 体积；② 反而诱导抄参照），
   防抄由**机械 n-gram 守卫**负责。
3. **实体检测器误判（自我修正）**：初版把引号内**纯中文描述性引语**（如「被读完并被理解」）
   当命名实体 ⇒ 假性"实体丢失"。已加**专名性判定**（引号内须含拉丁/数字，或以机构/定理后缀结尾），
   并把被丢弃的描述性引语记入 `quoted_dropped_descriptive` 以便审计。

**v4 开场对照（机制①落地的直接证据）**
- v3：「**先做一个假设。假设明天**有一份数学证明被公布出来…」（**命中禁止项**）
- v4：「**1977 年，Appel 和 Haken 宣布四色定理被证出来了**，数学界那会儿的第一反应不是鼓掌。」
  —— 事实切入 + 态度外露；且「几十万行」后紧跟**人话翻译**：
  「你一行一秒往下读，好几天不睡觉也读不完，人脑扛不住」（机制⑤落地）。

**provenance**：`mechanism_style_rewrite_proposition_preserving`。
**LIMITATION（登记）**：内容结论**继承 v3 谱系**——**未重跑 claim/事实核查链**（授权明令），
故 v4 的**事实层未经新的独立核查**；文体为**机制迁移**，与参照文本的 n-gram 重合由守卫机械保证为 0。
