## 2. ⚠️ #80 黑板**依然存在** —— 本轮**修正了 Phase 29 的诊断**（两处重要更正）

### 2.1 验收实测：黑板**逐点未变**
用与 Phase 29 **完全相同的时刻**复测（旧版 vs P30 版）：

| t (s) | 旧版 mean | **P30 mean** |
|---|---|---|
| 940 / 946 / 952 / 955 | 136.66 / 136.65 / 136.40 / 136.06 | **完全相同** |
| **958 / 961 / 964 / 967** | 18.63 / 18.19 / 18.79 / 18.79 | **完全相同** |
| **970 / 973 / 975** | 18.60 / 18.61 / 18.61 | **完全相同** |

**⇒ pause 真实化对黑板区零影响。** 音频侧修复虽然正确且必要（时基内容现已真实存在、
结尾静音已真实化），**但黑板不是音频侧问题**。

### 2.2 更正 ①（重要）：**Phase 29 的因果归因不完整**
Phase 29 判定「时基比内容长 16.25s ⇒ 视频轨内容耗尽后被补黑」。
P30 实测证明：**音频侧补齐后黑板不变** ⇒ **根因在视频侧**（末段素材窗口未覆盖其时间窗），
**不是**音频/时基缺口。Phase 29 的**量化**（时基 977.884 vs 内容 961.634）**仍然正确**，
但把它当作黑板**根因**是**不完整的**。**特此更正。**

### 2.3 更正 ②（重要）：**"深色画面"多为素材本身的正常暗色，不是技术性黑板**
全片 1 fps 灰度扫描显示**多段近黑**，逐景对照后确认它们是**素材固有暗色**：

| 景 | 窗口中点 mean | 说明 |
|---|---|---|
| S16p2 | **246.63** | 亮 |
| **S17p1 / S17p2 / S18p1** | **18.00 / 18.87 / 18.41** | **暗** |
| S18p2 / S19p1 / S19p2 / S20 / S21p1 | 136.28 / 136.16 / 134.03 / 136.57 / 136.40 | 有内容 |
| **S21p2** | **18.60** | **暗（唯一真缺陷所在，见下）** |

**池内素材固有亮度**（实测）：`Close-packed spheres.jpg` = **mean 42.54**（本片最暗素材）
⇒ 经 1.25 推近后在探针尺度约 **18** —— **与 S17p1/S17p2/S18p1 的观测值一致**
⇒ 这三景是**正常的暗色素材内容**（"密堆球"示意），**不是缺陷**，
**Phase 28/29 把它们与"纯蓝/黑板"混为一谈是错的**。（S21p2 亦引用同一暗素材。）

**真正的缺陷收窄为**：**S21p2 的尾部区间** —— 该段窗口 `[961.35, 978.63]`，
而**视频内容在 ~961.4s 即结束**，其后为补齐的深色 ⇒ **黑板尾长约 16–17s，仅此一处**。
（授权书要求的 `H7 片尾卡追加于 S21p2 之后` **正是覆盖该区间的正解**。）

### 2.4 授权书验收指标的**口径问题**（需裁定）
授权书写「全片无 ≥3s 连续近黑（motion_metrics 同源采样法）」。
**实测：交片 978 张抽帧中近黑 204 秒（20.9%），最长连续近黑 41s** ⇒ 指标**不通过**。
但按 §2.3 的证据，这 41s **包含正常的暗色素材内容**（密堆球示意段 S17p1–S18p1，
连续约 41s 跨 3 段）⇒ **该指标把"内容性暗场"与"技术性黑板"混为一谈**，
**按现口径无法通过、且不应通过**。
**建议**：把该指标改为**"尾部区间（最后一段窗口）无 ≥3s 补齐黑板"** 或
**"逐景暗度与素材固有暗度一致（而非纯黑 mean<5）"**（需授权）。
