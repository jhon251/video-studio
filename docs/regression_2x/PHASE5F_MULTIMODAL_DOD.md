## 1. 判定语义（最终口径，禁止变通）

| 最终结果 | 条件（**先命中先返回**） | 语义 |
|---|---|---|
| `UNKNOWN` | **J0** 所有层不可用 | 环境/模型故障 → 不判定 |
| `UNKNOWN` | **J1** 5-D 报结构性 UNKNOWN（`MMT_TEMPORAL_SPLIT`／`MMT_INSUFFICIENT_FRAMES`／`MMT_LOW_CONSISTENCY`） | 画面在时间轴上不是稳定状态 / 样本不足 → 语义结论失去前提（**优先级最高**） |
| `UNKNOWN` | **J2** 层间冲突（同时存在 MATCH 与 MISMATCH） | 不选边，显式记录冲突，交人工 |
| `MISMATCH` | **J3** 存在 MISMATCH 且无 MATCH | 内容错配必须被拦住（flagging 是安全动作） |
| `MATCH` | **J4** 全部可用层一致 MATCH（可用层 ≥ 2） | MATCH 是**断言**：需要所有证据层不反对 |
| `UNKNOWN` | **J5** 仅 1 层可用且其判 MATCH | 单层证据不足以宣称一致 |
| `UNKNOWN` | **J6** 其余（全 UNKNOWN／部分 UNKNOWN／期望域缺失） | **UNKNOWN 是合法最终结果**；交人工或补证据 |

**证据优先级（决策顺序）**：① 结构性证据（5-D 时序/样本）＞ ② 冲突 ＞ ③ 错配（MISMATCH）＞ ④ 一致 MATCH ＞ ⑤ 无法收敛（UNKNOWN）。
**禁止**：为减少 UNKNOWN 而调阈值、把 UNKNOWN 当作失败、用单层证据宣称 MATCH。

## 4. 明确不在本子系统范围内（Out of scope）

1. **自动换材/选材/redo**：任何素材变更只能由人工经 4-C 闭环执行（`select-candidate` + `redo`）。
2. **自动发布/上线**：Judge 不接触发布链。
3. **提高 MATCH 率**：本子系统**不**以 MATCH 率为目标；UNKNOWN 是合法结果。
4. **阈值调整**：`min_sim/margin/min_vote_frac/min_stability_cos/split_cos` 均冻结；改动属**契约变更**，需新授权。
5. **多镜头/运动素材的泛化**：当前真值集只覆盖静态素材项目（#43），泛化属未来研究项（R3）。
