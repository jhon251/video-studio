## 1. P29-1 #80 诊断：根因 = **时基比内容长 16.25s ⇒ 视频轨内容耗尽后被补黑**

### 1.1 逐景取证（实测）
| 时刻 | 画面灰度均值 | 判定 |
|---|---|---|
| 940–956 s | **136.3 ± 0.4** | 有内容 |
| **958–974 s** | **18.6 ± 0.3** | **近黑** |
| 976 s | 136.75 | 有内容（回落点，见 §1.4） |

**首个近黑时刻 = 958.0 s**，落在 **`S21p1`** 的声明窗口 `[942.47, 961.35]`；
`S21p2` 窗口 `[961.35, 978.63]` 中点 **969.99s ⇒ mean 18.60（近黑）** —— 与仲裁层 VLM
在 Phase 28 读出的「**纯深蓝色画面**」（S21p2）与「**深色背景加一行字幕**」（S18p1）**完全吻合**。
> `S21p1` 在 Phase 28 中「未调用仲裁」的原因查明：其 `corr` 为 `None`（抽帧/比对未产出分数），
> 仲裁层按 `SKIPPED_MISSING_INPUT` 处理 ⇒ 不是仲裁逻辑缺陷，而是**该景本身就落在近黑区**。

### 1.2 量化根因（确定性算术）
| 项 | 值 |
|---|---|
| voice 40 段**内容实测** Σ | **961.634 s** |
| pause 归因表合计（39 个边界） | **14.250 s** |
| trailing pad | **2.000 s** |
| **⇒ 声明的 `audio_time_base_s`** | **977.884 s** |
| **内容耗尽点**（Σ内容 + trailing） | **963.634 s** |
| **⇒ 黑板尾长** | **14.250 s**（+ 结尾 2s trailing，合计约 16.25s 无内容） |

**机理**：40 段 v2.1 时基把「**39 个边界 × pause**」计入时间轴，
**但 `narration.mp3` 的实际内容只有 961.634 s**；
时基比内容长 **16.250 s** ⇒ **视频轨内容用尽后被补齐（黑/深蓝）到音频时基**
⇒ 观众在末段看到"纯深蓝/深色画面"。
实测转黑点（958s）与内容耗尽点（963.6s）差 6.6 s，属转场/编码边界量级，**方向与量级一致**。

### 1.3 假设裁定（按授权书三条分支逐条给出证据）
| 授权书假设 | 裁定 | 证据 |
|---|---|---|
| **a) 窗口映射越界**（落进无旁白区） | **不成立** | 映射表 40/40 条、文本守恒 **3468==3468**、`assert_lineage` 通过；末段 `S21p1/S21p2` 都有 64/67 字旁白且窗口连续无缝 |
| **b) 绑定链断裂** | **不成立（已由 Phase 28 修复）** | Phase 28 绑定回退后 `checked` 达 **40/40**；末段绑定解析正常 |
| **c) 该窗口旁白无素材可配** | **不成立** | 末段有绑定（`S21p2` 的 `corr=0.000` 是"画面近黑 vs 素材"的比较结果，不是缺绑定） |
| **d)（本轮新增，成立）时基 > 内容 ⇒ 视频轨补黑** | **成立 ✔** | §1.2 的算术 + §1.1 的亮度实测 |

### 1.4 附带发现（如实登记）
`t=976s`（接近片尾）**亮度回落到 136.75**，与 958–974s 的近黑不一致 ⇒
**片尾最后 ~1–2s 存在一段非黑画面**（疑似末段最后一帧的重复/补齐或收尾帧），
与授权书「追加 H7 片尾卡在 `S21p2` 之后」的意图**恰好一致**——片尾卡会覆盖该区间。

## 2. 修复建议（供裁定，本阶段未执行）
| 选项 | 内容 | 代价/风险 |
|---|---|---|
| **① 把 pause 落成真实静音**（**推荐**） | 在 40 段音频的 39 个边界插入实际静音（或重切 narration 时按 pause 拼接）⇒ 内容总长 = 时基，黑板消失 | 需重切/重拼旁白音频（**零文本改动**），属"旁白重配"范畴，需授权 |
| ② 让 pause 不进入时间轴 | v2.1 已把**派生边界** pause 置 0；剩下的 14.25s 来自 **19 个原始边界 × 0.75** ⇒ 若要归零需改时基语义（P24-1 的 `PAUSE_BUDGET_S`） | 动 PI 时基语义，**超授权** |
| ③ 缩短时基到内容长度 | 直接把 `audio_time_base_s` 设为 961.634 + 2 = 963.634 ⇒ 黑板消失，但**总时长变 ~963.6s**（破 978.7±1 契约） | 破时长契约 |
| ④ 用片尾卡覆盖 | 按授权书在 `S21p2` 后追加 H7 outro ⇒ **只覆盖片尾约 2–4s**，**无法覆盖 14.25s 黑板** | 只能缓解，不能根治 |

**⇒ 真正的解是 ①**（把 pause 落成真实静音）。**②/③ 均触碰禁改清单或时长契约，不建议。**

   （见 §2 选项④）⇒ **直接重渲会得到一个仍然 fail-closed 的候选**，浪费一次 3 分钟渲染与预算；
3. 修复选项 ① 涉及**旁白音频重切/重拼**，属"旁白重配"，**需先取得授权确认**。
