## 1. P33-1 运动质量修复

### 1.1 诊断（对 v4.1 全 40 景、逐帧纯函数复算）
| 监理所指 | 实测结论 |
|---|---|
| ① zoom 居中锚定（消除右下净漂移） | **居中锚定本就成立**：`SLOW_ZOOM_IN` 的 `x0/y0 ≡ (src−w)/2`（逐帧断言通过）。所谓"右下漂移"实为**推近本身的几何后果**——窗口由中心收缩 ⇒ `x0` 由 240 增至 432（+192px），方向是**向内居中**，不是角偏移。 |

| ③ 平移方向按景平衡（禁系统性同向） | **确认是真缺陷**：19 个 `SLOW_PAN` 景**全部** `(+56, 0)` ⇒ 全片系统性向右漂移。根因：`direction` 恒为默认 `"RIGHT"`，`build_plan` 从未按景给方向。 |

### 1.2 修复
**③ 平移方向按景平衡**（唯一需要改的行为）：

同父景的派生段方向一致。**幅度上限（3% 画面宽）与整数帧纪律不变**。
实测：**LEFT 9 / RIGHT 10**（差 1，满足 ≤1），同向连续最长 1–2 景。

**① / ② 未做代码改动**：诊断证明二者在现行实现下**已经成立**（居中锚定逐帧成立、符号翻转 0），
按"不得为未知前提施加无效改动"的纪律**未改**；并已把二者写成**门**（下节），

## 3. P33-3 v4.1 配音入库（本阶段核心）

### 3.1 逐段合成
- **工具**：`edge-tts`（原音色 `zh-CN-XiaoxiaoNeural`，provider 与 `config.json` 一致）。
  **环境事实**：仓库内 `.venv_tts` **未装** edge-tts；GPT-SoVITS runtime 内为 **6.1.5**，
  该版本**已失效**（微软新增 `Sec-MS-GEC` 令牌 ⇒ **403**）⇒ 升级到 **7.2.8** 并
  **强制 IPv4**（本机可解析 AAAA 但无 IPv6 出口 ⇒ 否则 `Cannot connect to host`）。
- **结果**：**40/40 SUCCESS、0 重试**；`Σ实测语音 = 683.592s`（语速 5.07 字/秒）。
  逐段状态/字节/时长/文本哈希见 `output/phase33_voice/voice_output_v41.json` 与 `synth_ledger.json`。
- **完整性契约**：逐段独立状态 + 网络类可重试（指数退避）；**任一段失败 ⇒ fail-closed**
  （本轮 0 失败）。

### 3.2 新时基（**登记版本 `p33-v41-timebase-v1`**）
| 项 | 值 |
|---|---|
| 规则 | `Σ(逐段实测) + Σ(逐边界 pause) + trailing`，其中**逐边界 pause = 0**、trailing **2.0s** |
| Σ实测语音 | **683.592 s** |
| **新时基** | **685.592 s** |
| 整条旁白实测 | **683.592 s**（断言 Δ **0.000s**，容差 0.1） |
| 旧契约 | **978.7 ± 1 s 随 v3/V20 谱系废止**（已登记版本与理由） |

**⚠️ 两次实测踩坑（如实登记，均已在代码/口径中修正）**
1. **pause 归因缺失 ⇒ 幻影膨胀**：`narration_plan` 无 `pause_attribution` 表时回落到**冻结常量
   `PAUSE_BUDGET_S=0.75`** ⇒ 时基算成 **714.842s**，而音频只有 698.592s（**+16.25s 幻影**，
   即 KNOWN_ISSUES #75.2 的老病）。**修复**：voice 产物**携带归因表**。
2. **边界 pause 造成"音频比时间轴长"**：带 0.384615/边界后，生产
   `_build_material_timeline` **仍未把边界 pause 计入窗口**（实测 `Σ窗口 = Σactual + trailing`）
   ⇒ 成片比旁白**短 11.07s**（尾部静音，PI-2 `excess=11.072` 已如实记录）。
   **修复**：权威口径定为**段间不留额外静音**（pause=0）——因为 v4.1 是**逐段独立合成**，
   段间静音无来源；此后"音频事实 == 时间轴事实"。

### 3.3 新增一致性门：`tests/script_media_consistency_test.py`（**6/6 PASS**）

| C3 | 整片：`Σ(cue 文本) == Σ(narration)` | 字符级守恒（不漏段/不串段） |
