## 4. 要求特别复现的三点（一手证据）

### 4.1 S33-B02 的 G2 BLOCK

| 候选 | 尺寸 | 短边 | 门判定 |
|---|---|---|---|
| `r3_S33-B02_3` | 936×396 | **396 < 480** | **G2:BLOCK** + G3:DEMOTE → 不可用 |
| `r3_S33-B02_1` | 1280×720 | 720 | 门通过，但 **冻结 CV2 = NOT_USABLE** |

→ S33-B02 合格候选 = 0（该拍在现役 run04 母片中同样为 FALLBACK）。v1 之所以多算 1 拍，是因为它**只对新候选做分辨率检查**，把 `r3_S33-B02_3` 视为合格。

### 4.2 dHash 同簇冲突（三对全部 hamming = 0，即感知哈希完全相同）

| 冲突对 | hamming | 同簇 | 簇成员 |
|---|---|---|---|
| `ss2_S18-B02_8` ↔ `r3_S22-B02_2` | **0** | ✅ C880 | r3_S21-B01_4 · **r3_S22-B02_2** · r3_S30-B02_1 · **ss2_S18-B02_8** · ss3_S30-B02_3 |
| `ss2_S16-B03_11` ↔ `r3_S27-B03_1` | **0** | ✅ C953 | **r3_S27-B03_1** · **ss2_S16-B03_11** |
| `r3_S30-B01_1` ↔ `r3_S32-B03_4` | **0** | ✅ C983 | **r3_S30-B01_1** · r3_S30-B04_1 · r3_S30B-B02_2 · **r3_S32-B03_4** |

**级联链条（S18-B02 → S22-B02）**：政策按 `(可用性, -fit, mid)` 排序取第一个"内容未用且不与邻拍同内容"的候选：

```
ss2_S18-B02_0  (USABLE, fit 0.85, C821) → 跳过：C821 已被 S15-B02 使用
ss2_S18-B02_10 (USABLE, fit 0.72, C827) → 跳过：C827 已被 S17-B01 使用
ss2_S18-B02_8  (USABLE, fit 0.72, C880) → 采用 ⇒ C880 与 S22-B02 的唯一内容同簇 ⇒ S22-B02 退 HN
```

同理 S16-B03（首选 `_0`/C819 被占 → 取 `_11`/C953）使 **S27-B03** 失去唯一内容。

**S32-B03 的特殊性**：其冲突簇 C983 **完全由 run03 既有文件构成**（无新素材参与）——该冲突在 run04 就已存在并按同样规则判给更早的 S30-B01，故 S32-B03 在现役母片中本就是 FALLBACK。**它不是接入造成的损失，也不属于"失 2"**。

### 4.3 "得 23 / 失 2"是否完全解释 67 → 88

**是，完全解释。** 状态转移矩阵（run04 → run05，101 拍）：

| run04 \ run05 | PASS | NO_EXP | HN/BORROW |
|---|---|---|---|
| **PASS** | 58 | 0 | **2**（S22-B02, S27-B03） |

- CORRESPONDING：`67 + 23 − 2 = 88` ✅（23 得 = 20 PASS + 3 NO_EXP；2 失 = S22-B02/S27-B03）
- 域一致 PASS：`60 + 20 − 2 = 78` ✅
