# 声音克隆接入指南（路线 A：火山引擎声音复刻）

> 目标：把你的声音克隆音色接入 video-studio，为 SAO 10 分钟版配音。

## 第 1 步：录音（已完成准备）

朗读稿在 `C:\mp4agent\voice_ref\朗读稿.txt`。用手机录音后：
- 把文件放到 `C:\mp4agent\voice_ref\`，或在对话中直接上传附件
- 只录前 3~4 段（约 2~3 分钟）即可用于克隆；全录完可直接当备选旁白

## 第 2 步：火山引擎开通声音复刻

1. 注册/登录 [火山引擎控制台](https://console.volcengine.com/)（需实名认证）
2. 开通「语音技术」服务 → 进入「声音复刻」页面
3. 上传你的录音样本（按页面要求格式与时长）
4. 签署声音授权协议（本人声音），提交审核（通常几分钟~1 个工作日）
5. 审核通过后获得 **音色 ID（voice_type，形如 S_xxx）**

## 第 3 步：获取调用凭证

1. 控制台「语音技术」→ 应用管理 → 创建应用，获得 **APPID**
2. 获得 **Access Token**（一次性 Token 或长效 Token）
3. 集群默认 `volcano_tts`

## 第 4 步：填入配置

编辑 `config/config.sao10.json` 的 tools.tts 段：

```json
"tts": {
  "provider": "volcengine",
  "appid": "你的APPID",
  "token": "你的Token",
  "cluster": "volcano_tts",
  "voice_type": "S_你的音色ID"
}
```

## 第 5 步：重新配音并渲染

```powershell
cd C:\mp4agent\video-studio

# 重做配音任务（用克隆音色合成 12 段旁白并拼接）
python run.py --config config/config.sao10.json redo <voice任务ID>

# 重新渲染（自动混入克隆音轨）
python run.py --config config/config.sao10.json redo <render任务ID>
python run.py --config config/config.sao10.json loop p_561fc1226eba --auto-approve
```

> voice / render 任务 ID 用 `python run.py status p_561fc1226eba` 查看。
> 我把这些命令封装成一条 `voice <项目ID>` 命令后会更省事（待办）。

## 备选：阿里云 CosyVoice 声音复刻

流程类似：智能语音交互 → 声音复刻 → 上传样本 → 授权审核 → 获得 voice id。
接入时在 `tools/tts_tool.py` 增加 `aliyun_cosyvoice` 分支即可（接口位已留）。

## 注意事项

- 只克隆自己的声音；授权协议必须本人签署
- 声音复刻仅用于自己的视频配音，不得用于冒充他人/诈骗
- 若审核未通过，通常是因为样本噪音大/时长不足，重录即可
