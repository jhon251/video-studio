## 1. 目标与限制

**目标**：验证当前 Production Plan（8N 优化版）是否符合真实人工制作流程，暴露成本/素材/结构层面的不现实之处。

**限制（硬约束）**：
1. 不修改任何代码（含 `visual_planning.py`、成本模型、场景规则）。
2. 不新增 Agent。
3. 不接视频生成 / 素材库 / TTS / 发布。
4. 仅设计验证方案（本轮不执行）。

**诚实前提**：真实生产无法在本系统内发生，故"现实参照"是一份**文档化共识 rubric**（基于公开的科普/事实类视频制作工时与素材惯例），而非实测数据。审计结论表述为"相对该 rubric 的偏差"，不声称实证精确。

## 2. 现实参照基准（Reality Reference）

### 2.1 单人/小团队制作工时参考（分钟/场景）

| 视觉类型（visual_target） | 参考带 low–high | 素材可获得性 |
|---|---|---|
| 口播 + 大字标题卡 | 5–10 | 高（自拍） |
| 口播 + 全屏数字卡 | 5–10 | 高 |
| 结论大字卡 / 落版 | 5–8 | 高 |
| 结论口播 + 关键数字卡 | 8–15 | 高 |
| 结论口播 + 呼应画面 | 10–20 | 中（需呼应素材） |
| 事实核查字幕卡 / 来源截图 + 引注 / 核查清单卡 | 10–15 | 高 |
| 待补提示卡 / 转场字幕卡 | 3–5 | 高 |
| 数据可视化 + 证据截图 | 30–60 | 中高（自绘图表 + 网页截图） |
| 概念动画 + 口播 | 60–120 | 中（自做动画费时） |
| 实拍素材 + 数据角标 | 20–40 | 中（需实拍/素材） |
| 快切素材 + 大字标题卡 | 15–30 | 中（需快切素材） |

### 2.2 整片最低可行工时（合成门槛）

精修事实/科普视频的**整片最低可行工时**（含脚本迭代、录音重拍、剪辑合成、审校）：

> **≥ 2 小时 / 成品分钟**。即 10 分钟级视频 ≥ 20 工时，15 分钟级 ≥ 30 工时。

（8N 当前估算：VIDEO-10 = 7.0h、VIDEO-15 = 10.3h——按此门槛**显著偏低**，预期被第 5 项判 FAIL，见 §5.5。）

### 2.3 场景构成比例参照（事实/科普类）

| 构成 | 合理区间 |
|---|---|
| 纯口播/字幕卡（无视觉辅助） | ≤ 40% |
| 数据可视化 + 证据截图 | ≥ 25% |
| 动画（概念动画） | ≤ 30% |
| B-roll / 实拍素材 | ≤ 25% |

## 4. 审计方法（静态核对）

对每个样本的每个 scene，执行五步核对（纯数据，无网络/无生产）：

1. **成本核对**：8N 场景成本（role 映射）与 2.1 参考带比对，统计落在带内/带外。
2. **类型分布**：按 visual_target 归类，统计比例，与 2.3 四条区间比对。
3. **素材可获得性**：按 2.1 的"可获得性"列归类，统计"中/困难"占比并逐条列出。
4. **技术构成比例**：B-roll / 数据可视化 / 动画 / 纯口播 四类占比，与 2.3 比对。
5. **可行性**：8N 整片成本与 2.2 最低可行工时比对。

## 5. 验收指标与成功阈值

| # | 验证点 | 验收指标 | 成功阈值 |
|---|---|---|---|
| 1 | 成本估算准确性 | scene 级成本落在 2.1 参考带内的命中率 | **≥80%** 且整片总成本 ∈ [Σlow, Σhigh] |
| 2 | Scene 类型分布 | 四类构成比例 | 全部落在 2.3 区间内 |
| 3 | 素材可获得性 | "中/困难"素材场景占比 | **≤30%**，并逐条列出困难项 |
| 4 | B-roll/数据可视化/动画比例 | 动画≤30%、纯口播≤40%、数据可视化+证据≥25%、B-roll≤25% | 全满足 |
| 5 | 10-15 分钟可行性 | 8N 整片成本 vs 最低可行工时（2h/分钟） | VIDEO-10 ≥20h、VIDEO-15 ≥30h 为 PASS；低于为 **FAIL**（报缺口倍数） |

**预期结果（诚实声明）**：第 5 项大概率 FAIL——8N 成本模型（role 级、分钟级）不含脚本迭代/录音/剪辑合成/审校，故 7.0h/10.3h 相对 20h/30h 门槛约低估 2–3 倍。审计将如实报告该缺口及 scene 类型拆分，**不自动修改成本模型**。

## 6. 停止条件

1. 五项审计对全部样本完成、出报告后**停止**（一次性验证，不迭代调参）。
2. 出现"素材不可获得导致整片不可行"（如某 claim 全部 body 素材均不可得）→ 记为 **BLOCKED 项**如实报告，不自动替换素材、不接素材库。
3. 任何 FAIL/BLOCKED 项只报告事实/数据/根因，**禁止自动修复**。
