## A. 当前稿件最明显的 10 个「AI 文案」特征（实测，不是印象）

**先说一个反直觉的实测结果**：您点名的 12 类模板，在现稿里**几乎不存在**——
`随着` 0 · `近年来/巨大进展` 0 · `这意味着` 0 · `总的来说/综上所述` 0 · `可以预见` 0 ·
`值得注意的是/需要指出的是` 0 · `不仅…而且` 0 · `在…领域` 0 · `真正意义上的` 0 ·
`全新时代/范式` 0 · `抽象名词堆叠(技术突破/沉浸式体验/赋能…)` 0 ·
唯一命中是 `从…到…` 4 处（且 S13-B01 / S20-B03 是真实事实跨度）。

**所以「AI 科普稿感」不在词面，在结构。** 真正的问题是这 10 条：
