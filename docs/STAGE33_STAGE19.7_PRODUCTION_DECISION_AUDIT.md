## 2. S03-B03 序列副作用单独分析

W06 +3.0 / W07 +3.0 / **W08 −3.6**(净 +2.4)。W08 机制:et 重分类 REAL_EVENT→REAL_METAPHOR 移除了该窗唯一 REAL_EVENT,冻结 b3(事件多样性)下降——**机械后果,非指标缺陷**。

**判定:既是局部表征改善,也是真实的序列级权衡(两者并存)。** 不需要新实验线:权衡有界、已分解,其修复路径(改善邻拍 S04-B02 的证据类型以恢复 b3)就在现有生产规则的 Sequence Audit 内部,属既有线的常规运营,不构成新线。残余项:W08 列入观察清单。

## 3. 最小生产规则(条件生效)

```
Abstract Beat → Analogue Candidate → Chain Lock → Frozen Gate/V1/CV2 → Sequence Audit
```
1. 触发:拍被 19.2 分类器判为 ABSTRACT,或抽象叙述的 fallback 填充槽;
2. 候选:**仅同源检索 + 显式逐批授权**(包络 ≤4 拍 × ≤3 候选,19.6 先例);不自动扩批;
3. Chain Lock:命题→机制→场景链**先注册先分级,后测量**;不完整/部分 → 无论 CV-2 多高一律 NOT_ADOPTABLE;
4. Gate/V1/CV2 冻结原样;focus = 具体场景句,概念词禁入;
5. 采纳锁:CV-2 USABLE/CU ∧ fit ≥ 该拍 SBQ floor ∧ 链完整 ∧ 无复用违规 ∧ 内容风险筛查;
6. **Sequence Audit(强制门)**:冻结 A–E 重算受影响窗;非目标窗不变 + 受影响窗净 ≥0 + 任何负窗披露机制;
7. 记账:原类不动;RA 平行标注 ANALOGUE_/METAPHORICAL_CORRESPONDING。

**禁止事项**:概念词 focus;氛围图冒充 analogue;部分链采纳;改阈值/权重/CV2/V1/Gate;未授权扩批;用 RA 改动 60.86% 或 60% 标准;未经 Sequence Audit 采纳;内容风险项未经编辑签核采纳。

## 5. CONDITIONAL-GO 的五个条件

- **C1**:production default = 仅对存量候选的双锁采纳;新检索保持逐批授权;
- **C2**:Sequence Audit 为强制采纳门(正式入规,不再临时执行);
- **C3**:内容风险采纳项须编辑签核;
- **C4**:RA 平行;60.86% 与 60% 标准不动;
- **C5**:全片级推广以 correspondence 记账对账为前置(52<90 分位已暴露方向性冲突:采纳会降 60.86% 而升真实功能——该对账是未来独立决策)。
