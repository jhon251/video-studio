## B. 属视觉观察、无法单独证明工程根因的部分

1. **"头发特写"的精确措辞**: 2:10 帧面证据为前臂毛发+黑色织物躯干特写, 画面内不存在头部/头发。审片人对时间点或元素的措辞可能与帧面有偏移, 但"去语境异常特写"这一实质判断成立(根因=裁切)。
2. **"拼贴图"的定性**: 屏幕上是单幅带缺陷图表(缺字形+文字重叠+低分辨率), 不是多图拼贴。"拼贴感"来自文字层碰撞与豆腐块, 属渲染缺陷而非素材类型错误。
3. **"黑白纹理"的颜色归属**: 1:12–1:15 裁切画面实为彩色(花纹裙/地毯); 全片最接近"黑白纹理"的是 4:05–4:11 灰度神经横切图。两处同属"裁切后纹理化"根因族。
4. 以上三条**不影响 P0/P1 根因结论**; 三处锚点均已在帧级定位并归因。

## C. P0 根因(全局素材重复)

**代码级根因: `render_run2.py:52–81` 的借用算法没有任何全局复用约束。**

1. **去重作用域 = 单拍内部**(第 32–46 行): EVIDENCE 拍仅在本拍自己的候选池内选最优; 跨拍去重不存在。
2. **HN 借用**(52–64 行)与 **FALLBACK 借用**(66–81 行): 从拍位 i 出发按列表距离 d=2,3,… 向两侧找**最近的**有资产 EVIDENCE 拍, 直接引用其 asset 对象。**无已用集合、无单资产使用上限、无 chapter/全片配额、无时间距离惩罚**。
3. **d≥2 跳过邻拍的设计反而制造 A?A**: 当两个非证据拍夹一个证据拍时, 两者必然都借到同一资产(各距 2)→ S29-B02→B03→B04+S30-B02 四连同图、34 处 A?A 由此机械产生。
4. **乒乓的合成路径**: HN/FALLBACK 密集段中, 左右 HN 各向相反方向借不同资产, 形成 ABA/ABAB; 极端案例 S09B-B01/B02 与 S18B-B01/B02 两图在全片两处(相距 80+ 拍)互为乒乓。
5. **VIZ 图表复用是路由表硬编码**(exp_run02_route.py:16–113): viz2 阶梯图被显式指派 5 拍(含 S33B 结尾三连播), 无任何约束。
6. **字节级重复对去重不可见**: 3 对 MD5 全同文件以不同 material_id 存在(S10-B01↔S10-B02 相邻、S11-B01↔S11-B02 相邻、S16-B03↔S18-B01), retrieval 仅按 URL 去重, 相邻两拍各自"自己的素材"实为同一文件。
7. **MOTION_WORTHY 正则是死代码**(render_run2.py:93 定义未用)→ 全部剪辑为纯静帧, 重复呈现为逐帧相同的画面, 重复感最大化。
8. **fallback 并非"绕过"复用约束——约束根本不存在**; 39/90 照片槽(43%)上屏他人素材(26 HN 设计性借用 + 13 EVIDENCE 判定失败后转 FALLBACK 借用)。

## F. 缺失能力

1. **全局复用账本**: 无 per-asset 使用计数、无时间距离策略、无 chapter 配额——P0 的直接缺口。
2. **内容级去重**: 无字节 MD5、无感知哈希; material_id/URL 相等≠内容相等(已漏 3 对)。
3. **裁切后视觉复核**: CV2 判原图, 观众看裁切带——无人对"最终像素"负责。
4. **渲染前资产完整性 gate**: 分辨率/宽高比/拼贴/截图/文字密度/水印/实验状态/命名空间隔离全部缺失(viz3 1011×512+豆腐块直接上屏为实证)。
5. **实验/生产命名空间强制**: stage22 实验资产可被生产 render 直接读取。
6. **运动/去模板化**: Run02 路径为全静帧(MOTION_WORTHY 死代码), 与 Stage 16.2 冻结能力未接驳。

## G. 推荐 Global Reuse Policy(资产类型 × 叙事功能 × 时间距离, 取代一刀切 ≤2)

原则: 次数上限是手段不是目标; 约束对象是"观众感知到的重复", 由(类型, 功能, 距离)三元组决定。

| 资产类型 | 叙事功能 | 允许上屏次数 | 最小时间间隔 | 说明 |
|---|---|---|---|---|
| B-roll/氛围图 | 氛围 | ≤2 | ≥60s 或不同 chapter | 硬约束; 超出转 HN 借用或换池 |
| REAL_WORLD_EVIDENCE | 论点证据(不同拍各自主张) | 每拍须独立素材 | 相邻禁止 | 证据唯一性=可信度; 字节/感知重复禁止 |
| REAL_WORLD_EVIDENCE | 同一锚点回扣(呼应/总结) | 允许复用 1 次 | 章节首尾呼应位 | 需在 assignment 显式标 `callback_of`, 不计违规 |
| VIZ/图表 | 同一模型跨段引用 | ≤2 | 章节级隔离 | S33B 三连播此类必须拆分: 静态+高亮态+推进态三帧差异 |
| VIZ/图表 | 单拍讲解 | 1 | — | 禁止两拍共用同一静图 |
| narrative anchor | 结构锚点 | 允许按计划复用 | 显式注册 | 复用属叙事设计, 注册后豁免 |
| HN/fallback 借用 | 诚实中性 | 每借出资产 ≤1 个借用者 | 借用者互相 ≥2 拍 | 借用账本单独计数, 不与证据混算 |

执行规则(全部可离线计算):
1. 复用账本按**内容 ID**(MD5→dHash 分层)计数, 不按 material_id/路径;
2. 选择借用源时加双重惩罚: `score = distance − λ·use_count − μ·(同 chapter 已用)`, 替代"最近优先";
3. 违规时动作顺序: 换池 → 降级 HN(角标) → 空位(黑底+文字卡)——**禁止静默重复**;
4. 竖构图(AR<0.8)照片强制 CONTAIN_BG 或 crop_subject 复核, 不进入无监督 FULL_BLEED。

## H. 推荐 Pre-render Visual Integrity Gate(渲染前独立层, 位于 assignment 之后、build_clip 之前)

```
G0 存在性      文件存在且 >5KB, 可被 PIL/ffprobe 打开
G1 类型        MIME 实检(jpeg/png/webp); 与声明 source/类型一致
G2 分辨率      短边 ≥720px(全屏照片); 图表 ≥1280×720; 否则 BLOCK
G3 宽高比      0.6 ≤ AR ≤ 2.2; 超界 → 强制 CONTAIN_BG(禁止盲裁)
G4 内容重复    MD5 全库查重 + dHash(≤6/64 拒, 6–10 人工带); 跨拍相邻强制查
G5 拼贴/截图   启发式: 高频直线网格+多矩形分割+边缘密度异常 → 疑似拼贴/截图 → 人工带
G6 文字密度    OCR 或边缘投影估计; 图内文字面积 >8% → 标记"文字资产"走 CONTAIN_BG 且禁烧字幕重叠
G7 水印        角部高对比重复纹理模板 → 疑似水印 → 人工带
G8 出处/状态   asset 必须属于本 Run 命名空间; status=EXPERIMENT → BLOCK(豁免需显式授权标记)
G9 可追溯      beat→material_id→url→file→verdict 链逐项非空; 断链 BLOCK
输出: PASS / DEMOTE(CONTAIN_BG 等降级处置) / BLOCK(换池或空位卡)——全部门控决策写 manifest, 异常资产不得静默进入 render
```

配套两条渲染规则: (a) 裁切后帧送一次轻量复核(裁切带 dHash 与原图整图判定分离记录; 首选: 对 crop 后区域跑一次 CV2 复验或人脸/主体显著性检查, 防止"判定的是原图、上屏的是残带"); (b) 图表资产强制字体子集化预检(渲染 glyphs 无 tofu: 用 PIL 逐 label 渲染比对非空白)。

## J. 是否值得进入正式开发

**值得, 且优先级高**。依据: (1) 43% 照片槽上屏他人素材、12 处 ABAB、2 处相邻字节重复——观众可直接感知, 属成片质量硬伤; (2) 实验资产进入生产渲染属治理级缺陷(隔离被穿透); (3) 全部修复集中在 assignment/render 的**新增前置层**, 不触碰 Retrieval/CV2/冻结 14 件, 与 Stage 22 结论(VIZ Rollout 待授权)解耦, 可先行。建议开发顺序: 复用账本+策略(G) → 完整性 gate(H) → 裁切后复核 → 运动接驳(死代码复活)。

## K. 风险与可能的副作用

1. **去重收紧 → fallback/HN 上升**: 可用素材变少, 降级拍增多; 缓解: 借用账本独立计数 + 允许注册式锚点复用, I-1 实验先行量化(≤5pp 红线)。
2. **感知哈希误伤**: 同一设备的两张不同视角照片可能被判近重(本库 dHash≤10 仅 3 对且全为真重复, 误报风险低但存在); 缓解: 6–10 距离进人工带而非自动拒绝。
3. **追溯性与冻结边界**: 影子重指派若被误用于正式渲染会破坏 Run02 已冻结 artifact; 缓解: 实验输出全部落独立 namespace(audit_20260910/exp_*), 生产启用须新授权。
4. **VIZ 路线被 G8 卡死**: 在 Run 内 VIZ 生产能力建成前, 严格命名空间隔离会封禁全部实验图表; 缓解: G8 设显式授权豁免标记, 与 VIZ Rollout 授权决策绑定。
5. **锚点豁免被滥用**: callback 注册若无审核会变成新漏洞; 缓解: 豁免清单进 manifest 并计入 QA 报告。
6. **裁切后复核增加 CV2 调用成本**: 仅对 AR<0.8 或 crop_subject 拍触发, 预估 <20 拍/片。
