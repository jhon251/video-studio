> 状态：**仅诊断 + 架构压力测试 + 设计修订**。不实现、不渲染、不改 P1/3.2b/3.1.4/2.x/冻结稿、不调阈值、不进 P2、不 SEAL。

## 0. 检验红线（若文档任何一处违反，v3 即失败）

1. **任何 beat 的设计理由，不得以模板/枚举名作为主语**（"因为这是数据句，所以用 DATA_GRAPHIC"= 立即失败）；
2. **任何画面的第一理由必须是注意力或认知变化**（"观众第一眼看哪里、第二眼理解什么"必须写得出）；
3. **无素材句的设计必须包含 ≥1 个时序事件**（进入/揭示/变化/退出），否则等同 P1 的静态图形卡；
4. **任何 motion 必须能回答"删掉它观众损失什么"**，答不出 = 删掉。

## 1. 压力测试一：Visual Statement 会不会变成"高级模板系统"？

构造 10 个完全不同类型的信息句。每句回答 7 问。**理由语言只允许使用注意力/认知/关系词汇**（看哪里、理解什么、落差、转移、并置、过程感、体量感、焦点交接），模板名只可作为执行备注出现在括号里。

### 句 1（数据）：「全球每年约有八百万吨塑料进入海洋。」

1. **attention_target**：数字"八百万吨"与其"体量感"的落差——观众不必读完整句，只需"看见一个巨大的数量"。
2. **visual_evidence**：口播原文数字"八百万吨"（grounded；禁止换算成任何新数字）。
3. **无理想素材时**：把"八百万吨"做**体量对比锚点**：前景一个巨型数字（字号=半个画幅高度）+ 背景一条极细的水平线（海面），让"数字的体积"与"线的单薄"形成空间落差——注意力事件=数字先入、海面线后现。
4. **为什么比两个候选好**：候选 A=海洋垃圾照片（相关但不携带数量信息，观众看完仍不知道"八百万"多大）；候选 B=塑料制品特写（只有"物"没有"量"）。本设计的理由=**让观众先感知数量、再把它落到海面上**，信息顺序与句子顺序一致。
5. **第一眼**：巨型"八百万"三字（前景层）。
6. **第二眼**：理解"这个数量属于海洋"（背景海面线 + 小字"吨塑料"锚点，均来自原文）。
7. **前后关系**：前镜若在讲"海洋污染来源"，本镜是来源的**体量兑现**（从"是什么"跳到"有多大"）；下一镜应接"后果"（focus handoff：从数字→生物）。

### 句 2（因果）：「海水温度升高一两度，珊瑚就会开始发烧。」

1. **attention_target**：微小数字"一两度"与巨大后果"发烧"之间的**因果落差**——注意力的路径必须是"先小后大"。
2. **visual_evidence**：原文"一两度"（小）+ 原文"发烧"（大）；有海温视频素材时，视频即证据。
3. **无理想素材时**：两段式时序——先在前景出现极小号的"一两度"（与画幅对比显得微不足道），停留 0.8s；随后"发烧"二字以高对比色**放大进入**，挤占画面——**让观众用眼睛经历"小原因→大后果"的因果过程**，而不是读句子。
4. **为什么比候选好**：候选 A=珊瑚白化照片（只展示后果，丢失了"一两度"这个因果起点）；候选 B=温度计图形（只展示原因，丢失后果）。本设计=**因果关系的空间化**（小→大、进入→挤压）。
5. **第一眼**：极小的"一两度"。
6. **第二眼**："发烧"放大入侵 → 理解"小的变化造成大的后果"。
7. **前后关系**：上一镜若在讲"海水温度正在变化"（原因铺垫），本镜是原因的**兑现点**；下一镜承接后果（珊瑚白化画面或"赶走藻类"的机制）。

### 句 3（对比）：「珊瑚礁只占海底不到百分之一，却养活了四分之一的海洋生物。」

1. **attention_target**：两个分数的**并置落差**——"不到百分之一"与"四分之一"必须同时被看见，而不是先后读到。
2. **visual_evidence**：原文两个分数（grounded）。
3. **无理想素材时**：左右空间并置——左半幅一个极小的色块（体积≈画幅 1%，视觉化"不到百分之一"的占比），右半幅一个大色块（≈25%），中间一条细线；注意力事件=**两个体量同屏对比**，观众一眼完成"小养活大"的认知，不需要读任何句子。
4. **为什么比候选好**：候选 A=珊瑚礁照片（只有"美"，没有"比例关系"）；候选 B=两张照片并排（相关但比例不可见）。本设计=**把句子的核心关系（比例悬殊）变成空间体量**，这是照片无法携带的信息。
5. **第一眼**：两个色块的悬殊大小。
6. **第二眼**：理解"1% 养活 25%"。
7. **前后关系**：上一镜若是"珊瑚礁有多美/重要"（定性），本镜是**定量的证据升级**（从感受→数据）；下一镜应转向"它为什么脆弱"（focus 从比例→威胁）。

### 句 4（时间变化）：「过去三十年，这座城市的夜空越来越亮。」

1. **attention_target**：亮度**渐变过程**——观众要"看见变化在发生"，而不是看见两个静态状态。
2. **visual_evidence**：原文"三十年/越来越亮"；有城市夜景素材时以其为底。
3. **无理想素材时**：以城市剪影为背景层，前景层做**亮度与星点密度的缓慢升程**（时间行为=持续 3~4s 的明度渐变 + 星点渐隐）——观众在 4 秒里**亲历**"越来越亮"，时间本身成为视觉元素。
4. **为什么比候选好**：候选 A=亮夜城照片（只有结果状态）；候选 B=明暗两张图切换（只有两个状态，无过程）。本设计=**把"过程"作为画面主体**——句子的谓语是"越来越"，画面就演"越来越"。
5. **第一眼**：现在的夜空亮度。
6. **第二眼**：亮度仍在上升 → 意识到这是"三十年"的浓缩。
7. **前后关系**：上一镜若是"城市如何扩张"（空间变化），本镜是同一主题的**时间维度转写**；下一镜承接"光污染的影响"。

### 句 5（人物）：「她用了四十年，走遍了中国每一片湿地。」

1. **attention_target**：人物与"四十年/每一片"的**跨度**——焦点先落在"人"（单个），再扩展到"跨度"（空间）。
2. **visual_evidence**：原文"四十年/每一片湿地"；有人物素材时以其为主体。
3. **无理想素材时**：中景层放"人"的轮廓（最小化个体细节、强调单个人形），背景层做**湿地色块序列的横向缓慢铺开**（空间跨度）；前景锚点词只有"四十年"——注意力事件=人形静止、色块从人脚下向两侧延展。
4. **为什么比候选好**：候选 A=湿地风景（丢了"人"）；候选 B=人物特写（丢了"跨度"）。本设计=**"一个人 × 漫长跨度"的空间关系**，用静止的人与延展的空间对比表达坚持。
5. **第一眼**：单个静止的人形。
6. **第二眼**：她脚下的湿地一直铺向画面外 → 理解"四十年/每一片"的分量。
7. **前后关系**：上一镜若是湿地生态介绍（空间背景），本镜是**把背景落到具体的人**（focus 从环境→人）；下一镜承接她的发现或影响。

### 句 6（地理空间）：「台风从这里生成，一路向北，掠过整条海岸线。」

1. **attention_target**：**路径与方向**——观众的视线要跟着"生成→北上→掠过"移动。
2. **visual_evidence**：原文"这里/向北/海岸线"（空间关系词）；无真实地图数据时不画真实地理（只做示意图式路径）。
3. **无理想素材时**：背景层一条海岸线示意色带（垂直方向），中景一个"生成点"标记，前景做**标记沿色带向北的匀速位移**——注意力事件=视线被一个移动焦点牵引走完整条路径，方向（向北）就是句子的谓语。
4. **为什么比候选好**：候选 A=台风卫星图（真实但观众要自己找路径）；候选 B=静态示意图（有路径无运动）。本设计=**让眼睛执行"一路向北"这个动作**，运动即语义。
5. **第一眼**：生成点。
6. **第二眼**：点向北移动，扫过的即海岸线 → 理解"掠过"的含义。
7. **前后关系**：上一镜若是"海洋温度异常"（成因），本镜是**成因的空间展开**（focus 从温度→路径）；下一镜承接登陆后的影响。

### 句 7（动作）：「渔民把网撒下去，再慢慢收回来。」

1. **attention_target**：**动作的往复过程**——撒（向下、放开）与收（向上、收拢）两个相位。
2. **visual_evidence**：原文动作词"撒下去/收回来"；有渔民素材时以其为底（legacy S12 的渔民收网图即此类）。
3. **无理想素材时**：背景层渔网纹理（几何纹理底），中景做**网线的两相位缓动**：先整体下移+展开（撒），停顿，再上移+收拢（收）——动作本身成为主体，不需要真实人物。
4. **为什么比候选好**：候选 A=静态渔民照片（动作被冻结）；候选 B=渔网特写静态图（无过程）。本设计=**让观众经历"撒-收"的完整节奏**，运动幅度小但相位明确（下/停/上）。
5. **第一眼**：网向下撒开。
6. **第二眼**：网收回来 → 理解"反复的劳动"。
7. **前后关系**：上一镜若是"海面之下的变化"（对比铺垫），本镜是**水面之上的人类活动**（构成上下对比）；下一镜承接"很少有人看见"（focus 回到水下）。

### 句 8（情绪）：「时间会让一座城市逐渐失去记忆。」

1. **attention_target**：**"逐渐失去"的过程感**——观众要目睹一个东西从清晰到模糊/褪色。
2. **visual_evidence**：原文"逐渐失去"（过程词 grounded；本句无具体事实可造，只能演句子自己）。
3. **无理想素材时**：中景层一条城市天际线色块 + 前景锚点词"记忆"（原文词）；时序=先清晰呈现"记忆"二字与天际线，随后 4 秒内**同步缓慢降低不透明度与对比度**（褪色），最后只剩轮廓——"失去"被时间行为直接演绎，而不是被描述。
4. **为什么比候选好**：候选 A=老城照片（静态怀旧）；候选 B=城市夜景视频（只有城市没有"失去"）。本设计=**句子的谓语就是画面的时间行为**（褪色），观众在观看过程中产生"失去"的情绪体验，而不是被告诉。
5. **第一眼**：清晰的"记忆"与城市。
6. **第二眼**：它们正在褪去 → 情绪从"看见"转为"惋惜"。
7. **前后关系**：上一镜若是"城市的变化"（事实层），本镜是**事实的情绪化转写**（同一主题升一档抽象）；下一镜应收束或转希望。

### 句 9（抽象概念）：「什么是真正的自由？」

1. **attention_target**：**问题本身**——观众要进入"提问状态"，而不是被塞一个答案。
2. **visual_evidence**：原文"自由"（唯一可用的锚点词；本句无其他事实）。
3. **无理想素材时**：背景层留白（近全空），中景一个"自由"锚点词**极小且偏置一角**（体量上"不自由"），随后缓慢向中心**漂移+放大**（挣脱感）——注意力事件=词从角落向中心的移动，本身就是"自由"的空间隐喻；全程无答案文字。
4. **为什么比候选好**：候选 A=飞翔的鸟/开阔天空图（陈词滥调且非 grounded 素材）；候选 B=大字"自由"居中（把抽象词当标题，无体验）。本设计=**让"自由"以运动方式被体验**（从约束位置到开放位置），且不发明任何事实。
5. **第一眼**：角落里的"自由"。
6. **第二眼**：它正在移向中心 → 观众开始"想"这个问题，而不是"读"这个问题。
7. **前后关系**：本句类型决定它常作**开场或转折**：若为开场，本镜为全片建立"提问基调"（后续所有镜都是对这个问题的展开）；若为转折，前镜是"不自由的具体表现"，本镜是**从具象跳到抽象的 attention handoff**。

### 句 10（结论/号召）：「珊瑚礁的生死，取决于我们接下来十年的选择。」

1. **attention_target**：**"选择"落在观众身上**——观众必须感到这句话在对自己说话，而非旁白。
2. **visual_evidence**：原文"十年/选择/生死"；coral 有 S20 城市/海洋素材可作底。
3. **无理想素材时**：中景"生死"与"十年"两个锚点词并置，前景层在停顿 1.5s 后**让"选择"一词单独点亮**（高对比色+放大+其余元素压暗）——注意力事件=全片信息收束到唯一焦点"选择"，画面在"选择"处达到视觉复杂度最低值（**释放**），因为此刻该观众出场了。
4. **为什么比候选好**：候选 A=结尾风景+全句大字（信息过载，且"号召"没有焦点）；候选 B=静态标语卡（告知而非对话）。本设计=**用"先减后亮"的时间行为把选择权交还观众**——高潮在"选择"点亮的一刻，而不是堆满元素的一刻。
5. **第一眼**：并置的"生死/十年"。
6. **第二眼**："选择"点亮 → 理解这句话是对自己说的。
7. **前后关系**：作为 CONCLUSION，本镜承接全片 escalation 后的**释放**（复杂度和运动都降到最低，只留一个焦点）；结尾停帧 ≥1s 后收束。

**压力测试一结论**：10 句全部可用"注意力/认知/关系"语言完成设计，无一依赖模板名作为理由；每句都有 grounded 的证据元素与"无素材"时序方案 → v3 抽象层成立（比 P1 的"类型→模板"高一层）。

## 2. 压力测试二：没有好素材时怎么办？（v3 的生死问题）

| Case | 条件 | v3 处理 | 绝不退化为 |
|---|---|---|---|
| A | 有完美视频素材 | 素材即证据：视频为 midground 主体，镜头动作**只做一种**（或静止）；文字层只放 ≤12 字锚点 | 素材+全句字幕卡 |
| B | 只有一张相关图片 | 图片为 bg/mg，做**单焦点强调**：前景锚点词落在画面"空白区"，其余留白；运动=静止或单一推近（整数轨迹） | 图片+贴字 |
| C | 只有弱相关图片 | 图片降为**氛围层**（低对比、色罩统一），信息层由锚点词/图形承担——弱素材只提供"质地"，不承担"语义" | 硬用弱图当主体 |
| D | 有数据无视觉素材 | 数据=体量/比例/路径的**空间化**（见句 1/3/6 设计）：数字体量差、并置、方向位移；全部数字逐字来自原文 | 深色底+整句文字 |
| E | 有因果关系无拍摄对象 | 因果=**时序事件**：小→大（句 2）、点→路径（句 6）、并置→点亮（句 10）——关系被时间行为演绎 | 两张图左右贴 |
| F | 抽象概念（"时间会让一座城市逐渐失去记忆"） | 见句 8：**视觉隐喻=谓语的时间化**（褪色过程），分层=bg 天际线色块 + fg 锚点词，时序=清晰→褪去。全部 grounded（只用原文词，无新事实） | 深色底+大字 |

**反退化机制（写入 Validator 结构层，机器可查）**：
- 无素材 beat 必须存在 ≥1 个 `temporal_event`（进入/揭示/变化/退出），否则 REJECT；
- 图形 beat 的字量 ≤12（锚点词级），全文由字幕承担；
- 每画面必须有 `attention_target ∈ 画面元素`（Validator 核对 target 词出现在图形/锚点层中）。

## 3. 压力测试三：一条句子到底需要几个视觉层？

| 层数 | 何时用 | 理由 | 示例 |
|---|---|---|---|
| 1 层 | 素材本身携带全部信息时 | **少，但有理由**：让画面自己说话，任何添加都是噪音 | 完美的珊瑚鱼群视频（句"鱼群像彩带一样穿过"） |
| 2 层 | 素材需要**一个焦点**时 | 素材提供语境，锚点词/图形提供"看哪里" | 渔民图 + "撒下去/收回来"双相位动作（无文字层） |
| 3 层 | 需要**焦点+证据+锚点**同时成立时 | bg 氛围 / mg 主体 / fg 锚点词——每个层一个职责，缺一不可 | 句 8：天际线色块(bg) + "记忆"(fg) + 褪色变换(时间行为) |

**规则**：层数 = 注意力焦点数，上限 3；**新增一层必须新增一个注意力理由**（Validator 结构层检查"每层是否有独立职责"）；1 层设计是合法的且常常更高级——"堆东西"是 v3 明确的反模式。

## 4. 压力测试四：运动到底为什么存在？（Motion Decision Test）

**必答题**：把这个运动删掉，观众会损失什么？答不出 → 删掉。`motion_count` 不再是质量指标；**允许全片大量 HOLD**；**静止画面也可以是高级视觉设计**。

运动存在的仅三种合法理由：
1. **注意力转移**：引导视线从 A 到 B（句 6 台风路径的北移）；
2. **状态/过程表达**：谓语本身是过程（句 4"越来越亮"的升程、句 8"逐渐失去"的褪色、句 7"撒-收"往复）；
3. **信息展开**：从局部到全貌的揭示（"推近/拉远"只有在"有东西要揭示"时使用）。

六字段定义（v3 MotionSpec 修订）：
- `motion_necessity`：删除损失陈述（必填，非空）；
- `motion_semantic_relationship`：与注意力/谓语/展开的关系（必填）；
- `motion_smoothness`：**整数帧轨迹**（每帧位移 ∈ {0}∪[1,N]px、方向单调、三段缓动），jitter=0 为硬 Gate；
- `motion_amplitude`：必须**可被感知**（<0.5%/s 或 <1px/帧一律禁止——不可感知的运动只有代价没有收益）；
- `motion_duration`：默认短于 beat 的 60%，留出静止进入/停留；
- `start/end_continuity`：起止帧必须静止 ≥0.3s（无"突然开始/戛然而止"）。

**铁律重申**：`natural > meaningful > smooth > restrained`；HOLD = 绝对静止（0 位移）；废除 zoompan / 正弦微动 / 亚像素平移。

## 5. 压力测试五：镜头之间的关系（A→B→C，attention flow）

8 种关系机制（每镜必须声明 ≥1，Validator 结构层检查）：

| 机制 | 视觉定义 | 真实示例（coral） |
|---|---|---|
| continuation | 上一镜的颜色/运动方向/主体继续存在 | S04 鱼群（右向流动）→ S05 对比图仍保留右向构图趋势 |
| contrast | 同构图格，相反属性（明↔暗/静↔动/大↔小） | S13"饭碗消失"（静、暗）→ S14 小丑鱼（动、亮） |
| escalation | 复杂度/对比度/幅度递增 | S16→S17→S18：焦点逐渐收窄、对比逐级增强，S18 达到峰值 |
| release | 复杂度/运动降到最低 | S18 高潮后 → S19 沙滩孩子（暖、松、慢） |
| callback | 回收前文元素（母题的具体化） | S01"褪色的城市"冷调居中构图 → S20 同冷调同构回收 |
| attention handoff | 上一镜焦点元素在下一镜的同一位置**转化为新焦点** | S06 焦点=温度数字（画面中央）→ S07 焦点=海水（同一区域，由"温度"转成"酸化"） |
| scale change | 景别切换（近↔全） | S08"百分之一"（近、局部色块）→ S09 海龟（全、环境） |
| visual handoff | 上一镜的运动方向/元素形态被下一镜承接 | 句 7"撒-收"的向下运动 → 下一镜水下视角的向下视线 |

**示例链（coral 中段 attention flow）**：
> S06 焦点=温度数字（观众看着"一两度"）→ **attention handoff**：S07 同一画面位置出现"海水"锚点（温度落到海水）→ **escalation**：S08 焦点再收窄到"百分之一 vs 四分之一"体量对比 → **scale change**：S09 拉远到海龟穿过（环境）。观众视线始终被"交接"而非被"抛掷"。Validator 检查：每镜声明的关系类型 + handoff 焦点坐标与上一镜焦点坐标重叠度。

## 6. 压力测试六：节奏不能只靠时长（Visual Rhythm → Attention Curve）

**Attention Curve 定义**（每 beat 一个数值，由确定性公式算，人工只判"是否与感受一致"）：

```
attention = complexity × contrast × focus_concentration
complexity   = 层数(1-3) + 图形元素数(0-2)          （≤5）
contrast     = 前景/背景明度比 + 强调色面积比        （0-2）
focus_concentration = 1 / (焦点元素数)              （1/3-1）
```

- **节奏 = attention 曲线的一阶变化**，不是 attention 绝对值：高潮 = **变化率峰值**（前一镜刻意压低 → 高潮镜骤升），不是"堆最多东西"；
- 例：coral S18 为什么是高潮——S17（attention≈2，静）→ S18（attention≈4.5，唯一焦点"选择"点亮+对比最强）→ S19（attention≈1.5，release）。**是"落差"制造高潮**；
- machine 职责：计算曲线、检查单调段/落差段存在性；**人类职责：裁决"这个落差是否被感受到了"**；
- 补充指标：attention density（attention/时长，防"高复杂度长时间轰炸"）、motion density（运动时长占比，默认 <40%）、silence/release 段存在性（高潮后必须有 ≥1 个低 attention beat）。

## 10. 最终问题：如果 v3 仍比剪映难看，下一层真正缺失的能力是什么？

按"最可能瓶颈"排序的诚实判断：

1. **可执行的视觉生成/画面供给能力**（第一瓶颈）：剪映的核心优势是"为每句话产出一个像样的画面"，无论来源是素材库还是生成。我们的素材供给（3.1.4）是静态图库且覆盖受限（tea recall 0.25 级），而"锚点词+分层+时序"的确定性设计在**画面质感上限**上无法替代"一张真正的好画面"。v3 能把"没有画面"处理得不难看，但无法把"没有画面"变成"有画面"。
2. **真正的视频/图像理解能力**：我们没有任何视觉模型——不知道画面里有什么、焦点该裁在哪、这张图到底像不像"失去记忆"。v3 的一切构图与焦点都基于文本侧推理，**对画面的"理解"为零**。剪映（及其背后的多模态模型）知道画面内容，所以我们输在"看到"这一层。
3. **摄影/剪辑先验的编码深度**：专业剪辑师的"镜头语言库"远大于我们手写的 8 构图/6 运动。这不是模板数量问题，而是**先验知识的编码规模**问题——v3 的 statement 层能表达意图，但意图到"高级画面"之间还隔着数千条专业经验，我们只有几十条。
4. **更强的视觉评估模型**：无 VLM → "好不好看"永远依赖人工，规模化迭代速度受限；剪映有海量用户行为反馈作为评估信号。
5. **渲染/动效管线成熟度**：剪映级缓动、文字动画、调色是多年工程积累；我们的帧级管线能做到"不抖"，但离"优雅"仍有距离（这是工程问题，可在 v3 内持续逼近）。

**结论**：v3 的目标与承诺必须如实定界——**v3 能让系统达到"确定性、克制、有理由的视觉设计"上限（≈一个认真但资源有限的人工剪辑的静态+微动版），并消除 P1 的抖动与 PPT 感；但如果 v3 之后仍然明显不如剪映，第一瓶颈几乎必然是"画面供给与视觉理解"（第 1、2 条），那属于新的能力层（视觉生成/多模态理解），而不是继续在 3.3 的决策层上迭代。**
